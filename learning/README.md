## 学习方式

每一单元按同一顺序进行：

1. 不查答案，先写自己的初始判断和信心值；
2. 阅读中文正文，把主要论证改写成编号前提与结论；
3. 完成练习，尤其处理最强异议；
4. 对照自查标准，不对照“标准立场”；
5. 写下哪一条前提改变了、仍然怀疑什么、什么证据会继续改变判断。

学哲学不是记住作者赞成什么，而是逐渐获得四种能力：发现问题、辨认前提、承受异议、在理由改变时修订自己。

## 内容与证据的关系

仓库采用[仓库内中文学习契约](../curriculum/repository-learning-contract.md)：

- 公版或开放许可文本，在权利和底本明确时可收入完整中文翻译；
- 仍受版权保护的现代作品，以原创中文教材、论证重构和最短必要引文处理；
- 每个作者归属都保留版本与章节线索，但这些线索供复核，不要求学习者另读原版；
- 一份课程表、一张书单或一篇只告诉你“去读什么”的导读，不再算作完成的学习内容。

## 公开课程与私人补充

课程采用三层保存方式：

| 位置 | 保存内容 | 学习作用 |
|---|---|---|
| 本公开仓库 | 尽可能完整的原创中文正文、论证、案例、练习和答案标准 | 主要学习入口，普通读者不依赖其他材料 |
| [私人学习补充库](https://github.com/TruthNian/philosophical-reflections-private) | 所有者个人的译词卡、连续段落核验、私人学习稿与作答 | 只在版权或个人隐私不适合公开时补充；未获授权者无法访问 |
| 本地原典书库 | 购买或取得的 PDF、EPUB 与扫描本 | 只供编写和回源核验，不上传 GitHub |

私人补充不能成为缩减公开正文的借口。一个概念、一条主要论证或一项必要异议只要能用原创中文说明，就必须留在公开课程；只有连续原文、私人长篇翻译稿与个人记录进入私人层。
