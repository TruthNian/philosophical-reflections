# 论证不是争吵：从一个主张到可检验的理由结构

> 状态：可直接学习　建议用时：一周，共 5—8 小时

本单元以 Anthony Weston 的 *A Rulebook for Arguments* 第五版为主要编写底本，同时采用通行的非形式逻辑区分。无需阅读英文原书。目标是让任何哲学判断都能被拆开、检验、加强或放弃，而不是给文章加上“所以”“显然”便算完成论证。

## 一、论证的功能

争吵的目标常是压过对方，论证的目标是让一个结论获得可共同检查的理由。一个人独处时也需要论证，因为最容易被自己放过的，正是符合既有立场的跳步。

论证至少有两个部分：

- **结论**：希望别人或未来的自己接受的主张；
- **前提**：用来支持结论的理由、证据或较基础判断。

一段话可以有信息却没有论证，例如“昨夜下雨，路面很湿”只是并列报告。加入“因为昨夜下雨，所以路面很湿”才表明支持关系，但表明关系不等于关系成立。自动洒水、清洁车辆和时间间隔都可能削弱推理。

论证评估要连续问三件事：

1. **前提可接受吗**：事实可靠吗，概念清楚吗，价值前提能否辩护；
2. **前提相关吗**：即使为真，它是否真的增加结论可信度；
3. **支持足够吗**：是否遗漏反例、替代解释或必要前提。

把这三问缩成“我同不同意结论”，就失去了论证训练。

## 二、先把骨架写出来

考虑主张：

> 学校应把图书馆开放时间延长到晚上十点。许多学生白天上课或实习，现有座位在考试周也持续不足。延长开放能让这些学生获得与其他人相近的安静学习机会。

标准化后是：

1. 许多学生白天因课程或实习无法充分使用图书馆；
2. 考试周现有学习座位不足；
3. 延长开放能为这些学生增加可用的安静学习时间；
4. 学校应在成本合理时减少由课程安排造成的学习机会差异；
5. 因而，学校应把图书馆开放时间延长到晚上十点。

原段没有明说第 4 条，但没有它，事实不会自动推出“应当”。这叫**规范桥梁前提**。论证重构不是挑错，而是把说话者最可能愿意承担、又能使推理成立的前提补出来。若故意补上一条荒谬前提，得到的只是稻草人。

### 重构的五步

1. 用一句完整、可真可假的话写结论；
2. 列出直接支持结论的前提，不把例子和结论混在一起；
3. 给前提排序，使每一步的作用可见；
4. 补出没有它就无法过桥的隐含前提；
5. 删除修辞强度，保留实际理由。

同一个关键词应保持同一含义。“自由”若在前提中指不受国家干预，在结论中却变成拥有实现目标的资源，论证已经换轨。精确重复往往比华丽同义替换更可靠。

## 三、短论证的四项压力测试

### 1. 前提可靠性

“大家都知道”“研究证明”“历史一再表明”不是证据来源。事实前提要问样本、测量、时间、范围与来源；价值前提要问是否一致适用、是否忽略相关利益、能否承受反例。

前提并非必须绝对确定。它只需在当前论证中达到相应强度：医疗决策、刑事定罪和选择午餐需要不同证据门槛。结论强度不能超过证据。小样本可以支持“值得进一步调查”，通常不能支持“永远如此”。

### 2. 相关性

一位科学家在物理学上权威，并不因此在税制上权威；一个政策名称令人温暖，也不证明政策有效；批评者生活虚伪，也不自动使其批评为假。

相关性问题常被情绪词遮住。把“冷酷的削减”“疯狂的扩张”改写成可测量描述，再看论证还剩什么。若形容词一删，理由就消失，原段主要在施加态度而非提供支持。

### 3. 充分性

一个真实且相关的理由仍可能不够。公共交通能减排，不足以单独证明任何线路方案；某人曾撒谎，不足以证明这次陈述为假。需要判断证据覆盖多少替代可能，并让结论保持相称。

### 4. 反例

全称命题只需一个真实反例便失败。“所有自愿交易都公平”会被极端信息不对称或生存胁迫挑战。反例不总是否定核心洞见，也可能迫使结论缩小为“在知情、无强迫且外部成本得到处理时，自愿交易通常有正当性优势”。被反例修订后的主张往往更强，因为它知道自己的边界。

## 四、从例子作一般化

由若干个案推出一般结论，需要检查：

- **数量**：样本是否足以覆盖结论范围；
- **代表性**：样本如何进入观察，是否只看见最响亮或最容易接触的人；
- **基准率**：某现象在总体中原本多常见；
- **测量一致**：不同案例是否用同一标准；
- **反例分布**：失败案例是偶然噪声，还是集中在某类条件下。

“我问过五个朋友，他们都讨厌远程办公”几乎只说明朋友圈。即使五人回答诚实，选择机制也让样本不能代表全体劳动者。

基准率尤其容易被忽略。某测试对患病者有 95% 检出率，不等于阳性者有 95% 概率患病；如果疾病极少见，假阳性可能多于真阳性。哲学论证不必都做统计，但凡使用“常常”“大多数”“典型”就已经承担分布主张。

一个高质量的一般化会主动寻找反例，而不是把反例留给对手。目的不是自我削弱，而是识别结论在哪些条件下成立。

## 五、类比能证明什么

类比论证的形式是：

1. 对象 A 与对象 B 在性质 x、y、z 上相似；
2. A 还具有性质 q；
3. x、y、z 与 q 之间存在相关联系；
4. 因而，B 也可能具有 q。

关键不是相似点有多少，而是相似点与结论是否相关。公司和国家都有预算，不能据此推出国家应像家庭一样永远不得负债；国家能够征税、发行货币并跨代存续，这些差异恰与债务结论相关。

检验类比时列四栏：已知相似、已知差异、相似为何支持结论、差异是否切断支持。若论证只靠形象冲击而说不出第三栏，它更像隐喻。

类比常适合发现问题和形成初步推测，较少单独承担强制结论。它的结论语言应与强度相称：从“值得类推”到“极可能如此”之间差别很大。

## 六、诉诸来源并不等于迷信权威

现代人不可能亲自验证所有事实。合理依赖证言需要判断：

1. 来源是否在当前问题上有相关能力；
2. 是否接触了一手证据；
3. 是否说明方法和不确定性；
4. 是否有明显利益冲突；
5. 独立来源是否交叉一致；
6. 引用是否忠实于原语境。

“专家也会错”不能推出“专家意见没有证据价值”；“许多专家同意”也不能替代方法检查。共识的力量来自多条相对独立的训练、数据和纠错路径，而非头衔计票。

网络来源还要核对发布日期、原始出处、修改记录和链接是否真的支持当前句子。二手文章引用一项研究时，应返回摘要、正文或正式数据，而不是引用转述者对标题的理解。

哲学文本的权威使用另有一层：证明“某作者说过什么”时，原典是证据；证明“作者说的是真的”时，作者身份本身不是证据。归属问题与真理问题必须分开。

## 七、因果推理

相关性是因果线索，不是因果结论。发现 A 与 B 同时变化后，至少比较五种结构：

1. A 导致 B；
2. B 导致 A；
3. 第三因素 C 同时导致 A 与 B；
4. A 与 B 互相强化；
5. 相关来自选择、测量或偶然。

例如，常读新闻的人政治参与更高。可能是新闻促进参与，也可能是本来关心政治的人更常读新闻，还可能是教育程度同时影响两者。要加强因果判断，可以寻找时间先后、机制、剂量变化、自然实验、干预结果和替代解释被排除的程度。

哲学中的因果论证常含规范桥梁。即使证明某平台设计导致焦虑，也还需说明为何减少这种伤害比平台自由、社交收益或实施成本更重要。事实因果与政策结论之间不能跳跃。

复杂性不是逃避判断的借口。“原因很多”仍允许比较哪一个因素必要、充分、可改变或贡献最大。成熟结论会说明因果层次，而不是在“唯一原因”和“完全无关”之间二选一。

## 八、演绎论证：形式保证与前提负担

演绎有效意味着：如果前提都真，结论不可能为假。有效性只检查结构，不保证前提为真。

### 肯定前件

1. 如果 P，那么 Q；
2. P；
3. 所以 Q。

### 否定后件

1. 如果 P，那么 Q；
2. 非 Q；
3. 所以非 P。

### 假言三段论

1. 如果 P，那么 Q；
2. 如果 Q，那么 R；
3. 所以，如果 P，那么 R。

### 析取三段论

1. P 或 Q；
2. 非 P；
3. 所以 Q。

### 反证法

1. 暂时假定 P；
2. 从 P 推出矛盾或不可接受结果；
3. 所以拒绝 P。

两种常见无效形式很像有效推理：

- **肯定后件**：如果下雨，地会湿；地湿；所以一定下雨。遗漏洒水等其他充分原因；
- **否定前件**：如果下雨，地会湿；没下雨；所以地不湿。同样遗漏其他原因。

哲学论证经常把争议藏在条件句里。“若道德客观，就必须存在非自然道德实体”形式上可以参与有效推理，但这个条件前提本身极具争议。形式清楚不是内容已经证明，而是让争议终于落到可见位置。

## 九、长论证是一棵树

长文不是一个前提列表，而是多层支持结构：

- 主结论由若干主理由支持；
- 每个主理由又需要事实、原则或子论证；
- 有些前提必须合在一起才产生支持，有些理由各自独立；
- 异议可能攻击前提、连接、范围或替代方案；
- 回应应修改对应节点，而不是在文章末尾统一宣称“仍然如此”。

写作前先画树：顶部放主结论，下一层放两至四个主理由，再向下追问每个理由凭什么。若一个节点无法得到支持，要么补证据，要么缩小结论，要么删除整条枝干。

一篇论证文章的最小结构是：

1. 精确主张和适用范围；
2. 问题为何真实存在；
3. 最强的两三条正面理由；
4. 最强异议的完整版本；
5. 回应后对原主张的实质修订；
6. 剩余代价和改变结论的条件。

“有人可能反对”后接一个显然愚蠢的观点，不算处理异议。强异议应当由一个聪明、了解材料且价值取向不同的人愿意认领。若回应没有迫使正文任何部分改变，往往说明异议还不够强。

## 十、常见谬误应当作为故障位置

背诵拉丁名称不如指出推理在哪里失效：

| 故障 | 结构 | 修复方向 |
|---|---|---|
| 人身攻击 | 从说话者缺点推出主张为假 | 说明缺点是否影响其证据接触或可信度 |
| 稻草人 | 把对方主张改弱后击败 | 引用其最强版本并让对方可能认可 |
| 错误两难 | 把多个选项压成两个 | 列出混合方案、程度差异与未知项 |
| 循环论证 | 前提换词重复结论 | 寻找独立可接受的支持 |
| 诉诸无知 | 未证明为假便当作真 | 区分举证责任与暂缺证据 |
| 滑坡 | 从第一步直接跳到灾难终点 | 为每个过渡给出机制和概率 |
| 以偏概全 | 从偏小或偏置样本推广 | 扩大并解释取样机制 |
| 转移话题 | 用另一真问题替代当前问题 | 回写原结论，看理由是否仍相关 |

同一种表面形式并不总是谬误。刑事案件中被告无需证明无罪，是举证责任的制度安排；批评证人的利益冲突，也可能直接影响证言可靠性。诊断必须说明当前语境中的相关性，不能只贴标签。

## 十一、完整示范：是否应禁止课堂使用生成式人工智能

先写一个过强结论：

> 学校应禁止所有课堂中的生成式人工智能，因为它让学生不再思考。

压力测试后发现：

- “所有课堂”范围过大；
- “不再思考”是未经测量的绝对因果主张；
- 禁止是否有效、会否妨碍正当辅助尚未比较；
- 论证没有区分代写、反馈、翻译、无障碍辅助和教师示范。

修订论证：

1. 某些学习目标要求学生独立完成回忆、推演或写作，作品才可作为其能力证据；
2. 在这些任务中，未披露地让生成式系统产出关键推理，会使提交物不能证明目标能力；
3. 课程有责任保护评估结果的真实性，同时不应禁止与目标相容的工具使用；
4. 因而，学校应按任务目标规定使用边界：独立能力评估中禁止代做并要求披露，反馈、比较和辅助用途则另行设计。

最强异议是：检测不可靠，严格规则会惩罚诚实者并扩大资源不平等。回应不能只是重申诚信，而应改变制度方案：减少以成品文本单独定分，加入现场复现、过程记录、口头说明和允许范围明确的工具训练。

修订后的结论比“全面禁止”更窄，却更可执行，也更能承受现实异议。这就是论证训练的目标：不是守住原句，而是让理由决定句子最后能有多强。

## 十二、练习

### 练习 A：标准化

把下段写成编号论证，补出规范桥梁：

> 城市中心的私家车占用了大量公共空间，短途驾车还增加空气污染。城市应当把两条道路改成公交与自行车优先道。

### 练习 B：样本

某应用商店页面有 800 条评论，其中 72% 给出五星。分别写出支持和削弱“多数用户满意”的三项信息。

### 练习 C：类比

评估“国家预算就像家庭预算，所以政府绝不应借债”。列出两个相关相似、三个相关差异，并写出最多能推出的较弱结论。

### 练习 D：因果

观察发现每天使用社交媒体三小时以上的青少年焦虑评分更高。至少画出四种因果结构，并为每一种写一项可区分证据。

### 练习 E：有效性

判断下列推理是否演绎有效；无效时给出前提真而结论假的情形：

1. 若制度公平，则规则公开；规则不公开；所以制度不公平；
2. 若制度公平，则规则公开；规则公开；所以制度公平；
3. 不是提高税收，就是削减服务；不提高税收；所以削减服务；
4. 若人有自由意志，就有人能回应理由；有人能回应理由；所以人有自由意志。

### 练习 F：论证树

从以下命题任选一个，画三层论证树并写 1200 字短文：

- 大学教育不应主要按就业收入评价；
- 匿名网络发言是一项有条件的自由；
- 幸福不是评价人生的唯一尺度。

必须给出一个会迫使结论缩小的异议。

## 十三、参考分析

### 练习 A

一个可辩护的重构是：

1. 城市中心道路是稀缺公共空间；
2. 私家车在运输人数相对较少时占用大量该空间，并造成可避免的短途污染；
3. 公共空间分配应在基本通行得到保障的前提下，优先提高单位空间可服务人数并减少对他人的污染成本；
4. 把两条道路改为公交与自行车优先道，预计比现状更符合第 3 条；
5. 所以城市应实施改造，但需监测无障碍、配送与交通转移后果。

第 4 条仍需流量、替代路线和实施数据支持。补出桥梁不等于桥梁已经为真。

### 练习 B

支持信息包括：评论者由系统随机邀请、五星比例在大样本和多个时期稳定、未评论用户的留存与满意调查一致。削弱信息包括：只有极少数用户评论、商家用奖励换取五星、删除负面评论、用户群已因不满大量流失。800 很大，却不能用数量弥补选择偏差。

### 练习 C

相关相似可以是收入有限、借债需要偿还；相关差异包括政府可征税、寿命跨越个人世代、能为具有长期收益的公共资产融资、某些政府能发行货币、宏观衰退时政府支出会影响总需求。较弱结论是：政府借债也有机会成本和偿付约束，应按用途、利率、增长、代际分配与货币条件评估，不能因“不是家庭”便无限借债。

### 练习 D

至少包括社交媒体导致焦虑、焦虑促使更久使用、孤独或家庭压力同时导致两者、双向强化，以及测量或选择偏差。纵向时间顺序、随机或准实验限制使用、机制指标、控制第三变量、自然停机事件，都能提供不同强度的区分证据。

### 练习 E

1. 有效，是否健全取决于条件前提；
2. 无效，是肯定后件，规则公开还可能只是形式透明；
3. 若“或”穷尽所有可能则有效，但首项可能是错误两难；
4. 无效，是肯定后件，回应理由也可能由相容论、训练或计算过程解释。

## 十四、通过标准

闭卷完成以下任务即通过：

- 把一段 150 字议论改写成不超过七步的编号论证；
- 为它补出一个桥梁前提，并说明该前提怎样被检验；
- 区分前提不真、理由不相关和支持不充分；
- 为因果主张列出至少三个替代结构；
- 识别肯定后件与否定前件；
- 提出一个能使自己结论真正修改的异议。

如果只会给对方贴“谬误”标签，却不能给出更强重构，尚未通过。
