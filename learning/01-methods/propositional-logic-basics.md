# 命题逻辑起步：把“必然推出”变成可检查的结构

> 状态：可直接学习　建议用时：一周，共 5—8 小时

命题逻辑暂时不判断“正义”“自由”这些概念是什么意思，只研究完整命题之间怎样由“并且”“或者”“如果……那么”“并非”连接。它的价值不是让哲学变成符号，而是把一种关键要求精确化：有没有可能让前提全真而结论仍假？

## 一、学习目标

完成后应能：

- 区分命题、句子和论证；
- 用五个基本联结词符号化中文句子；
- 找到公式的主联结词与作用范围；
- 用真值表判断公式的真值、逻辑性质和论证有效性；
- 区分有效、健全、真实和有说服力；
- 使用六条基础推演规则完成短证明；
- 识别肯定后件、否定前件和对条件句的常见误读。

## 二、命题与符号

**命题**是可以为真或为假的内容。同一命题可以由不同句子表达，“雨停了”和 “The rain has stopped”在合适语境中可表达同一内容。疑问、命令和单独的感叹通常不是命题。

先用大写字母代表不能再由本系统拆开的原子命题：

- P：现在下雨；
- Q：道路湿滑；
- R：比赛取消。

五个基本联结词如下：

| 名称 | 符号 | 读法 | 为真的条件 |
|---|---|---|---|
| 否定 | ¬P | 并非 P | P 为假 |
| 合取 | P ∧ Q | P 并且 Q | P、Q 都真 |
| 析取 | P ∨ Q | P 或者 Q | 至少一个为真 |
| 条件 | P → Q | 如果 P，那么 Q | 除 P 真而 Q 假外都真 |
| 双条件 | P ↔ Q | P 当且仅当 Q | P、Q 真值相同 |

命题逻辑中的“或者”默认是**相容或**：两项都真时整个析取仍真。“茶或咖啡但不能都要”要写成 `(P ∨ Q) ∧ ¬(P ∧ Q)`。

## 三、作用范围与主联结词

括号不是装饰。比较：

- `¬(P ∧ Q)`：不是 P 与 Q 同时成立；
- `¬P ∧ Q`：P 不成立，而 Q 成立。

第一式允许 P 真 Q 假，也允许 P 假 Q 真；第二式只在 P 假 Q 真时成立。

一个复杂公式最后把两大部分连接起来的符号叫**主联结词**：

- `(P ∧ Q) → R` 的主联结词是 `→`；
- `¬(P → Q)` 的主联结词是 `¬`；
- `(P → Q) ∧ (Q → R)` 的主联结词是中间的 `∧`。

没有括号时采用约定优先级：`¬` 最强，其次 `∧`、`∨`，最后 `→`、`↔`。正式分析时宁可多写括号，不靠读者猜。

## 四、把中文翻成公式

### 必要条件与充分条件

“P 是 Q 的充分条件”表示有 P 就有 Q：`P → Q`。

“Q 是 P 的必要条件”表示没有 Q 就没有 P，同样是：`P → Q`。

因此：

- “通过考试必须注册”写作 `通过 → 注册`；
- “注册就一定通过”写作 `注册 → 通过`，两者完全不同；
- “只有注册才可考试”写作 `考试 → 注册`；
- “如果注册就可考试”写作 `注册 → 考试`。

中文的“只有”经常引起方向错误。先问：句子在排除哪种组合？“只有 Q 才 P”排除 P 真 Q 假，所以写 `P → Q`。

### 除非

“除非 Q，否则不 P”可写成 `¬Q → ¬P`，与 `P → Q` 等值。日常“除非”有时还暗示 Q 足以带来 P，但逻辑上的最低承诺通常只是 Q 必要。

### 既不……也不

“既不 P，也不 Q”写成 `¬P ∧ ¬Q`，也等值于 `¬(P ∨ Q)`。

### 并非所有

命题逻辑不能分析“所有”内部的量词结构，但应先避免中文错误：“并非所有人都同意”不等于“所有人都不同意”。前者只说至少有一人不同意，后者强得多。量词逻辑会专门处理这一区分。

## 五、完整真值表

当 P、Q 各可真可假，共有四种组合：

| P | Q | ¬P | P ∧ Q | P ∨ Q | P → Q | P ↔ Q |
|---|---|---|---|---|---|---|
| 真 | 真 | 假 | 真 | 真 | 真 | 真 |
| 真 | 假 | 假 | 假 | 真 | 假 | 假 |
| 假 | 真 | 真 | 假 | 真 | 真 | 假 |
| 假 | 假 | 真 | 假 | 假 | 真 | 真 |

条件句最容易误解。`P → Q` 只排除“承诺了 P 足以带来 Q，结果 P 出现而 Q 没出现”这一种情况。当 P 根本未出现时，条件句没有被反例推翻，因此在真值函数定义下为真。

这不表示日常所有“如果”都只是材料条件句。反事实、因果、相关性和承诺条件还包含额外内容；命题逻辑先抽取最低真值结构。

## 六、重言式、矛盾式与偶真式

- **重言式**在所有赋值下都真，例如 `P ∨ ¬P`；
- **矛盾式**在所有赋值下都假，例如 `P ∧ ¬P`；
- **偶真式**有时真有时假，例如 `P → Q`。

重言式因形式为真，却不提供关于现实的具体信息。“要么下雨，要么没下雨”不会告诉你是否带伞。矛盾式不能在任何赋值下成立；如果一组前提合起来形成矛盾，在经典逻辑中它们可以推出任意结论，这说明前提集已经失去区分能力。

## 七、逻辑等值

两个公式在每一行真值都相同，就逻辑等值，记作 `≡`。常用等值包括：

| 名称 | 等值式 |
|---|---|
| 双重否定 | `¬¬P ≡ P` |
| 条件消去 | `P → Q ≡ ¬P ∨ Q` |
| 逆否 | `P → Q ≡ ¬Q → ¬P` |
| 德摩根律一 | `¬(P ∧ Q) ≡ ¬P ∨ ¬Q` |
| 德摩根律二 | `¬(P ∨ Q) ≡ ¬P ∧ ¬Q` |
| 双条件 | `P ↔ Q ≡ (P → Q) ∧ (Q → P)` |

逆否命题与原条件句等值，但**逆命题** `Q → P` 和**否命题** `¬P → ¬Q`通常不等值。把“若有火则有氧气”倒成“若有氧气则有火”显然错误。

## 八、有效与健全

论证**有效**，表示不存在一行让所有前提为真而结论为假。有效性不要求前提现实为真：

1. 所有鲸都是昆虫；
2. 所有昆虫都会写诗；
3. 所以所有鲸都会写诗。

它的结构有效，前提却荒谬。一个演绎论证只有结构有效且前提都真，才叫**健全**。

真值表检验步骤：

1. 为所有原子命题列出 `2ⁿ` 行赋值；
2. 逐列计算每个前提和结论；
3. 只看前提全真的行；
4. 若其中有任何一行结论为假，论证无效，该行就是反例；
5. 若没有反例行，论证有效。

### 示例

检验 `P → Q, Q → R, P ⊢ R`：

当三个前提都真时，P 真迫使 Q 真，Q 真又迫使 R 真，因此不可能出现前提全真而 R 假。论证有效。

检验 `P → Q, Q ⊢ P`：取 P 假、Q 真。条件句真，Q 也真，但 P 假，得到反例，所以无效。这就是肯定后件。

## 九、六条基础推演规则

真值表可以机械检验，推演则展示结论怎样一步步得到。

### 肯定前件

`P → Q, P ⊢ Q`

### 否定后件

`P → Q, ¬Q ⊢ ¬P`

### 合取消去

`P ∧ Q ⊢ P`，也可推出 Q。

### 合取引入

`P, Q ⊢ P ∧ Q`

### 析取三段论

`P ∨ Q, ¬P ⊢ Q`

### 假言三段论

`P → Q, Q → R ⊢ P → R`

证明 `P ∨ Q, P → R, Q → R ⊢ R` 还需要分情况：若 P，则由第一条条件得到 R；若 Q，则由第二条条件得到 R；析取保证至少一个分支成立，所以 R。这个形式叫析取消去或分情况证明。

## 十、逻辑能做什么，不能做什么

逻辑能发现结构性跳步：结论是否必然跟随，条件句是否倒置，否定是否越过错误范围。它不能替你决定原子命题是否真实，也不能独自判断分类是否恰当、来源是否可靠、价值前提是否正当。

“若提高总幸福的行动都正确，而欺骗提高总幸福，则欺骗正确”可以形式有效。真正争议在第一前提是否过宽、第二前提如何测量、是否遗漏权利与长期后果。符号化的意义正是把这些内容问题从结构问题中分离出来。

## 十一、二十道练习

设 P＝“政策降低排放”，Q＝“政策增加成本”，R＝“政策应当实施”。

1. 下列哪项是命题：关上门；门关着；门关着吗；真糟糕。
2. 符号化“政策没有降低排放”。
3. 符号化“政策降低排放并且增加成本”。
4. 符号化“如果政策降低排放，那么政策应当实施”。
5. 符号化“政策只有在降低排放时才应当实施”。
6. 符号化“政策既不增加成本，也不应当实施”。
7. 符号化“政策要么增加成本，要么不应实施，但不能两者都真”。
8. 指出 `¬P ∨ (Q ∧ R)` 的主联结词。
9. 指出 `¬(P ∨ Q) → R` 的主联结词。
10. 当 P 真、Q 假、R 真时，计算 `(P ∧ ¬Q) → R`。
11. 当 P 假、Q 真时，计算 `P → Q` 与 `Q → P`。
12. 判断 `P ∨ ¬P` 属于重言式、矛盾式还是偶真式。
13. 判断 `P ∧ ¬P` 属于哪一类。
14. 用等值式改写 `¬(P ∨ Q)`。
15. 用不含 `→` 的公式改写 `P → Q`。
16. 判断 `P → Q, P ⊢ Q` 是否有效。
17. 判断 `P → Q, Q ⊢ P` 是否有效；无效时给反例赋值。
18. 判断 `P ∨ Q, ¬P ⊢ Q` 是否有效。
19. 判断 `P → Q, ¬P ⊢ ¬Q` 是否有效；无效时给反例赋值。
20. 判断 `P → Q, Q → R, ¬R ⊢ ¬P` 是否有效，并写出推演步骤。

## 十二、答案与解析

1. “门关着”是命题；其余分别是命令、疑问和感叹。
2. `¬P`。
3. `P ∧ Q`。
4. `P → R`。
5. `R → P`。“只有 P 才 R”把 P 规定为 R 的必要条件。
6. `¬Q ∧ ¬R`，等值于 `¬(Q ∨ R)`。
7. `(Q ∨ ¬R) ∧ ¬(Q ∧ ¬R)`。
8. 主联结词是 `∨`。
9. 主联结词是 `→`；左侧整体是 `¬(P ∨ Q)`。
10. P 真且 ¬Q 真，所以前件真；R 真，因此整个条件句真。
11. `P → Q` 真，`Q → P` 假。条件句只在前件真、后件假时为假。
12. 重言式。
13. 矛盾式。
14. `¬P ∧ ¬Q`。
15. `¬P ∨ Q`。
16. 有效，肯定前件。
17. 无效；令 P 假、Q 真，则两个前提真而结论假。
18. 有效，析取三段论。
19. 无效；令 P 假、Q 真，则条件前提与 ¬P 都真，¬Q 却假。这是否定前件。
20. 有效。由 `Q → R` 和 `¬R` 用否定后件得 `¬Q`；再由 `P → Q` 和 `¬Q` 得 `¬P`。

## 十三、通过检查

闭卷重新完成第 5、7、10、17、19、20 题，并自己创造一个肯定后件的生活例子。六项全对后，再用真值表检查以下论证：

`(P ∨ Q), (P → R), (Q → R) ⊢ R`

若能找出所有前提全真的行，并说明为什么其中没有 R 假的反例，就达到起步要求。错题必须记录错误类型：符号化方向、作用范围、真值计算或有效性概念。只改答案而不说明错因，不算完成。
