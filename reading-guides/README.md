# 原典导读

原典导读帮助读者真正进入一部作品，但不代替作品本身。

每份导读会回答：

- 这部作品试图解决什么问题；
- 为什么要在这个历史位置提出问题；
- 第一轮应当读哪些章节，按什么顺序读；
- 核心概念怎样互相规定；
- 主要论证如何重构；
- 哪些解释仍有争议；
- 最强异议是什么；
- 读完应当留下什么成果。

所有导读遵循[统一标准](GUIDE-STANDARD.md)。受版权保护的现代译本不会被复制到仓库；导读提供章节定位、短引文和合法来源。

若要从一部作品转入核心问题、方法和思想史课程，使用[跨层学习导航](../curriculum/cross-index.md)。导读负责进入文本，不单独承担完整课程。
