# 原典中文学习页

这里把一部原典中真正需要掌握的问题、概念、论证和争议写成可独立理解的中文学习正文。学习者不需要另读外文原版；章节、节号和版本信息用于编写端回源核验，也为自愿深入文本的人保留入口。

每份学习页会交付：

- 这部作品试图解决什么问题；
- 为什么要在这个历史位置提出问题；
- 内容应当按什么顺序理解，各章节在整体中承担什么工作；
- 核心概念怎样互相规定；
- 主要论证如何重构；
- 哪些解释仍有争议；
- 最强异议是什么；
- 完成后应当能够复现什么、写出什么。

所有页面遵循[统一标准](GUIDE-STANDARD.md)与[仓库内中文学习契约](../curriculum/repository-learning-contract.md)。公版或开放许可作品可在权利明确后加入完整中文翻译；受版权保护的现代作品以原创中文正文、论证重构和最短必要引文处理。

若要从一部作品转入核心问题、方法和思想史课程，使用[跨层学习导航](../curriculum/cross-index.md)。学习页负责一部具体作品，跨作品比较和长期训练由课程层组织。
