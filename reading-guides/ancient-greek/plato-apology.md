# 柏拉图《苏格拉底的申辩》导读：一种生活怎样接受城邦审判

## 一、作品身份

公元前 399 年，苏格拉底在雅典以不敬城邦诸神、引入新的神灵之事和败坏青年等罪名受审并被判死刑。柏拉图的 *Apologia Sōkratous* 以苏格拉底第一人称呈现辩护、量刑建议和判决后的讲话；*apologia* 指辩护，不是认错道歉。

文本通常被归入柏拉图较早作品，但具体写作日期不能精确确定。它不是法庭速记：柏拉图以文学形式重构一场真实审判。历史上的苏格拉底、作品中的“苏格拉底”和柏拉图作为作者必须分开。引用使用斯特凡努斯页码 **17a—42a**；选择含此编号的中文译本。

## 二、核心问题

1. 承认无知为何可以是一种智慧？
2. 哲学审查对个人和城邦有什么正当性？
3. 当保全生命与不放弃被认为正当的生活冲突时，应怎样选择？

## 三、历史语境

雅典刚经历战争失败、寡头政变与民主恢复。苏格拉底的部分交往者具有争议政治经历，但法庭审理的是正式宗教与教育罪名，不能把政治背景直接当成未写出的法律罪名。

苏格拉底先回应长期流传的“旧控告”：把他与自然研究、智者收费教学和把弱论证变强的形象相连；阿里斯托芬《云》是这种公共形象的重要见证。随后才质询正式控告者美勒托。安倪托、吕孔亦列名控方。文本因此同时审判一个人和一种已经被城市想象固定的哲学形象。

## 五、概念结构

| 概念 | 在文本中的作用 |
|---|---|
| 人类智慧 | 不是拥有最高知识，而是不把不知道的事假装成知道 |
| 反诘 | 通过追问显示自称知识者的信念冲突；它不自动给出正面答案 |
| 照料灵魂 | 使正义、德性和判断优先于财富、名望与生存 |
| 神的使命 | 神谕、梦与神示为持续审查提供行动根据，其公共证成仍可争论 |
| 伤害 | 作品倾向把真正伤害连接到变得不义，而非只受外在损失 |
| 省察 | 对自己与他人的理由进行持续检验，不等于无休止内省 |

## 六、论证重构

### 知道无知为何是一种有限智慧（20c—23b）

1. 德尔斐神谕宣称没有人比苏格拉底更智慧；
2. 苏格拉底自认没有通常意义上的重大知识，因此以查访方式检验神谕；
3. 政治家、诗人和工匠中的若干受访者有知识或成就，却又把局部能力扩张为并不拥有的智慧；
4. 苏格拉底与他们一样缺少最高知识，但没有同样确信自己知道；
5. 因而，他只在承认知识限度这一有限意义上更智慧。

隐藏负担在第 3 步：对话中暴露矛盾是否足以证明对方不知道？样本能否代表一类人？第 1 步的神谕又是调查起点、修辞框架还是柏拉图要求读者接受的权威？

### 为什么不应因死亡威胁放弃哲学（28b—30c）

1. 把未知的死亡断言为最大恶，是把不知道的事装作知道；
2. 不义和违背正当使命是已可辨认的恶；
3. 不应为逃避一种未知后果而选择已知的不义；
4. 哲学审查是苏格拉底认定的正当使命；
5. 因而，即使释放以停止哲学为条件，他也不应接受。

论证是否成立取决于第 4 步能否获得超出私人确信的理由。

## 七、解释争议

- **历史可靠性：**作品可能保存真实辩护的结构或精神，但不能逐句当作庭审记录；应与色诺芬及其他证据比较。
- **苏格拉底式反讽：**“不知道”是方法姿态、有限知识主张，还是更彻底的认识立场？文本同时包含强烈的道德确信。
- **民主与哲学：**苏格拉底是以公共理性服务城邦，还是以私人神命把自己置于普通公民判断之外？
- **失败还是成功：**作为求生的法庭辩护，它失败了；作为展示何种生活值得保全的哲学行动，它可能有不同成功标准。

## 八、最强异议

苏格拉底要求城邦接受持续质询，却以自己对神谕和使命的解释作为最终行动根据。他能揭露别人的无知，不等于已经证明自己的实践改善城邦，也不等于个体可以在公共程序中自授例外。

回应不能只说“苏格拉底是对的”。需要证明反诘带来的羞耻或混乱怎样转化为德性，以及私人良知与共同法律冲突时有什么可普遍采用的判准。

## 九、跨文本连接

- 《游叙弗伦》把审判前的宗教自信送入定义反诘；
- 《克里同》把逃亡机会与服从法律问题正面化；
- 《理想国》把灵魂照料、知识与城邦结构扩展为系统方案；
- 爱比克泰德继承了外在损失与人格伤害的区分，却置于斯多亚理论中。
