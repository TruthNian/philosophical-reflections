# 哲学随想

> 把艰深的思想还原成能够进入生活的语言。

我一直对哲学感兴趣，却也常被它晦涩的表达挡在门外。许多真正重要的问题——怎样理解自己，怎样与他人相处，怎样面对自由、责任、孤独、死亡与共同生活——不应只留在专业术语里。哲学之所以重要，正在于它能够帮助人辨认自己的生活，并在没有现成答案时形成判断。

这个仓库用来学习、记录和继续发展这样的思考。学习者不需要先读懂外文原典，也不需要在书籍与网站之间来回拼接材料；仓库中的中文正文应当独立交付问题、概念、论证、异议、练习和自查。原典由编写端阅读核验，为中文内容提供可追溯的证据。

它不以建立一套封闭的哲学体系为目标，也不限于某一位思想家；它从一篇原典、一个具体困惑或一种生活经验出发，把文本读清楚，把问题说清楚，再留下可以继续修正的理解。

## 写作方式

- **从问题进入。** 先说明一个思想与生活的关系，再处理术语和背景。
- **回到文本。** 涉及作者原意、历史变化或引文归属时，尽可能找到原始材料和稳定出处。
- **使用清楚的中文。** 不以晦涩模拟深刻，不保留只有形式而不能帮助理解的双语排版。
- **区分不同声音。** 原文、转述、历史说明和个人思考各自标明，不把编者的想法写成作者原话。
- **让文章自足。** 同一主题的正文、解释、思想变化、版本说明和来源尽量放在同一篇文章里，使读者不必在档案式页面之间来回拼接。
- **允许思想生长。** 新材料可以补充旧理解，真实的立场变化也应当被保留。

- [《我如何看世界》：独立、责任与思想的变化](articles/Einstein/how-i-see-the-world.md)

## 仓库边界

这里的文章是面向普通读者的哲学随想，但不会用“易懂”代替准确。涉及历史人物时，能确定的文本事实、基于材料的解释和编者自己的判断会分开书写。文章可以有个人立场，也应当让读者看见它建立在什么材料之上。

仓库不收录用户提供的受版权保护 PDF，也不重新分发第三方扫描件。公版或开放许可文本在权利状态明确时可以制作完整中文翻译；仍受保护的现代作品采用原创中文教学正文、论证重构与最短必要引文。原创文章、可授权中文译文和编者说明，在贡献者有权许可的范围内采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)；具体边界见 [RIGHTS.md](RIGHTS.md)。

所有者另有一个[私人学习补充库](https://github.com/TruthNian/philosophical-reflections-private)，用于个人译词、连续段落核验、私人学习稿和作答。未获授权者无法访问；原始购书文件仍只保存在本地，不上传 GitHub。公开课程不能用私人链接代替主要正文。

文章按思想人物或独立主题分类保存，使同一条问题线能够跨越多位作者与多种传统。
