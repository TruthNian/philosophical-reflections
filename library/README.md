## “原始版本”怎样落实

1. **能直接阅读原文时保留原文。** 先秦文献保存文言文本；笛卡尔保存拉丁文；康德与维特根斯坦保存德文；龙树保存梵文，并同时保留鸠摩罗什汉译。
2. **读不懂的语言不转嫁给学习者。** 原文和英译承担编写端核对功能，实际学习内容由仓库中文教材交付。只有原文而没有编写者可可靠使用的译本时，才列入待取得清单。
3. **古代作品不存在可供下载的“作者原稿”。** 此处的原始版本指可靠传承的原文、学术机构转录或能够识别出版信息的历史版，不把来历不明的电子文件当作原典。
4. **译者与版次属于作品身份。** 同名书的不同译本并不等价；书目尽量记录译者、年份、出版社、ISBN、标准章节号或通行定位法。
5. **旧英译只作为可开始的底本。** 公版历史英译让学习不必停下，但遇到关键术语与争议段落时，课程会指向现代译本升级项。

## 收录标准

一个文件只有完成身份与内容核验，才标记为“已入库”：

- 公开下载文件来自作者或译者授权页面、出版社、大学、公共数字图书馆等可识别机构；用户提供的私人文件单独记录版本与包装来源，不因内容正确便推定其发行来源；
- 作品、作者、语言、译者或出版信息能够从文件内部或来源页确认；
- 公开取得路径不绕过付费墙；私人文件不进入 GitHub，也不向他人提供下载；
- EPUB 能作为 ZIP 正常打开并含书目元数据，PDF 未加密且页数合理，HTML/TXT 含预期章节或标志性段落；
- 长篇扫描本抽查封面、书名页、目录和正文页，确认不是预览、入口页、错书或空白文件。

“网上能搜到”不是版本证据。文件正文正确、文件包装可信、公开传播有权，是三项不同判断；核验记录不把其中一项冒充另外两项。

## 编写端使用次序

1. 根据[中文学习入口](../learning/README.md)的编写次序选择下一个单元；
2. 用[课程核心书目](core-bibliography.md)确定主版本，用本地文件回查作者归属、章节与译词；
3. 遇到底本缺口时查[取得清单](acquisition-list.md)，不临时接受一个无法识别版本的替代文件；
4. 新文件记录出版信息、来源类别与取得日期，完成格式、目录、开头、结尾和抽样正文检查；
5. 重算 [SHA-256](SHA256SUMS.txt)，更新清单状态和书库快照；
6. 学习者只接收由这些证据编写并通过闭卷检查的中文单元。
