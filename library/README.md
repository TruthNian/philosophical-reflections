## “原始版本”怎样落实

1. **能直接阅读原文时保留原文。** 先秦文献保存文言文本；笛卡尔保存拉丁文；康德与维特根斯坦保存德文；龙树保存梵文，并同时保留鸠摩罗什汉译。
2. **读不懂的语言不充当学习版本。** 原文可以承担核对功能，实际精读另配中文或英文版本。只有原文而没有可读译本的作品，仍列入待取得清单。
3. **古代作品不存在可供下载的“作者原稿”。** 此处的原始版本指可靠传承的原文、学术机构转录或能够识别出版信息的历史版，不把来历不明的电子文件当作原典。
4. **译者与版次属于作品身份。** 同名书的不同译本并不等价；书目尽量记录译者、年份、出版社、ISBN、标准章节号或通行定位法。
5. **旧英译只作为可开始的底本。** 公版历史英译让学习不必停下，但遇到关键术语与争议段落时，课程会指向现代译本升级项。

## 收录标准

一个下载文件只有同时满足以下条件，才标记为“已下载”：

- 来源是作者或译者授权页面、出版社、大学、公共数字图书馆、Project Gutenberg、Wikisource、SuttaCentral、GRETIL 等可识别机构；
- 作品、作者、语言、译者或出版信息能够从文件内部或来源页确认；
- 下载路径公开、合法，不绕过付费墙，不采用网盘转存或来源不明的扫描件；
- EPUB 能作为 ZIP 正常打开并含书目元数据，PDF 未加密且页数合理，HTML/TXT 含预期章节或标志性段落；
- 长篇扫描本抽查封面、书名页、目录和正文页，确认不是预览、入口页、错书或空白文件。

“网上能搜到”不是版本证据。书库没有采用搜索聚合站、Anna’s Archive、无出处网盘和把网页入口伪装成 EPUB/PDF 的导出文件。

## 实际使用次序

1. 执行[十二周起步课程](../curriculum/00-orientation/twelve-week-launch.md)，从本页确认每周文本是否已经在本地；
2. 用[课程核心书目](core-bibliography.md)进入十个核心问题域和七条思想史主干；
3. 遇到“待购”时查[购买清单](acquisition-list.md)，按 P0、P1、P2 次序取得，不临时接受一个来历不明的替代文件；
4. 新文件放入相应目录，记录出版信息、来源与取得日期，完成格式和内容检查；
5. 重算 [SHA-256](SHA256SUMS.txt)，更新清单状态和书库快照。
