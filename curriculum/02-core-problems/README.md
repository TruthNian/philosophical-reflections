# 十个核心问题域：让世界观经受系统压力

这一阶段不按哲学家排队，也不追求把所有学说记住。它选择十组无法绕开的根本问题，让学习者不断完成同一件事：说出自己相信什么，找出理由，接受最强反例，再把原来的答案改写得更准确。

每个模块用四周、约 32 小时完成。十个模块合计约 320 小时；若每周学习八小时，正好是四十周。这里的“完成”不是读完列出的全部材料，而是提交并修订规定成果。

## 为什么是这十组问题

一个能够指导生活的世界观，至少要回答五层追问：

1. **我凭什么相信？**——知识、真理、语言与解释；
2. **世界和我是什么？**——实在、因果、时间、心灵、自我与意识；
3. **我能做什么？**——自由、行动与责任；
4. **我应当怎样生活？**——幸福、德性、道德与价值；
5. **我们要共同创造什么？**——权力、正义、科学、宗教、艺术、技术、自然与未来。

十个模块不是十只互不相干的抽屉。对意识的理解会改变责任观，对真理的理解会改变政治争论，对善的生活的理解会改变技术选择。课程因此既有建议次序，也要求持续回写旧答案。

| 顺序 | 模块 | 它给后续课程提供什么 |
|---:|---|---|
| 1 | [知识与真理](01-knowledge-and-truth.md) | 信念、证成、怀疑和真理的基本区分 |
| 2 | [实在、因果与时间](02-reality-causation-and-time.md) | 对“存在”“原因”“变化”的本体论承诺 |
| 3 | [心灵、自我与意识](03-mind-self-and-consciousness.md) | 行动者及其持续存在的模型 |
| 4 | [自由与行动](04-freedom-and-action.md) | 能动性、控制与责任条件 |
| 5 | [幸福、德性与善的生活](05-happiness-virtue-and-good-life.md) | 人生评价的对象与尺度 |
| 6 | [道德与价值](06-morality-and-value.md) | 行动正当性与价值客观性的争论 |
| 7 | [权力、正义与共同生活](07-power-justice-and-common-life.md) | 从个人规范进入制度规范 |
| 8 | [语言、解释与理解](08-language-interpretation-and-understanding.md) | 对前七个模块所用概念和文本的反省 |

次序可以调整，但不宜一开始只挑与既有立场最亲近的模块。哲学训练的价值恰恰来自遇到阻力。

## 每个模块怎样运行

四周任务都服从同一结构：

| 周次 | 核心动作 | 不可替代的成果 |
|---|---|---|
| 1 | 划定问题、写初始立场、掌握关键区分 | 一份[问题档案](../templates/question-dossier.md) |
| 2 | 精读原典、重构一个最强论证 | 两张[阅读卡](../templates/reading-card.md)与一张[论证图](../templates/argument-map.md) |
| 3 | 引入对立立场或另一传统、做现实检验 | 一次钢人化异议与一份[对话记录](../templates/dialogue-record.md) |
| 4 | 写短论文、接受批评、核对来源、整篇重写 | 一份[论文工作稿](../templates/paper-workshop.md)及其修订版 |

“原典”不等于“古书”。一篇改变争论结构的现代论文也可以是原典。导论只负责建立地图，不能代替对具体论证的阅读。

## 贯穿四十周的世界观账本

另建一个持续修订的文档，每完成一模块记录四项：

- 我目前的核心主张；
- 我愿意用什么理由支持它；
- 什么证据或论证会使我改变；
- 它与其他模块中的哪些主张冲突。

到第十模块结束时，把十组答案压缩成一页。若各答案只是并排放置而不能相容，这一页就会暴露裂缝；裂缝不是失败，而是下一轮学习最有价值的问题。

## 综合考核

完成十个模块后提交三项综合成果：

1. 一张跨模块概念图，至少标明十五条支持或冲突关系；
2. 一篇 4000—6000 字论文，处理至少三个问题域之间的真实冲突；
3. 一份修订说明，逐项比较阶段开始与结束时的世界观，并说明三处实质变化。

单个模块按[课程评估标准](../assessment.md)评分。全部模块完成且综合论文达到 70 分，才能进入思想史主干；否则回到最薄弱的两个模块补做，而不是靠累计阅读量过关。
