# 权力、正义与共同生活：强制何时获得正当性

共同生活离不开规则、资源分配和集体决定，也始终伴随强制。政治哲学的起点不是先选择阵营，而是追问：谁有权制定规则，受规则者为何负有服从义务，制度怎样分配自由、机会、风险和发言权，权力又如何进入家庭、市场与知识生产。

## 一、问题边界

本模块处理四个相连问题：

1. **政治权威：**国家何时拥有发布有约束力命令的权利？
2. **合法性：**强制制度即使不完美，何时仍可被正当化？
3. **正义：**基本制度应怎样分配权利、机会、资源、地位与风险？
4. **权力：**人的行动范围、偏好和“正常”标准如何被制度与社会关系塑造？

国家有能力迫使人服从，是描述性权力；国家有权统治，是规范性主张。法律有效也不等于道德上正当。

## 二、关键区分

| 区分 | 为什么重要 |
|---|---|
| 国家 / 政府 / 社会 | 反对某届政府不等于否定国家，社会权力也不只来自国家 |
| 权力 / 权威 | 能使人服从不等于有权要求服从 |
| 合法律 / 合正当 | 依法制定的规则仍可能严重不义 |
| 正当统治 / 服从义务 | 国家可有权执行某规则，个人未必因此在所有情形都负有服从义务 |
| 消极自由 / 积极自由 / 无支配 | 不受干涉、能够自我治理、免于任意权力是不同理想 |
| 平等 / 优先 / 充足 | 拉平差距、先改善最差者、让人人过线并不等价 |
| 程序正义 / 实质正义 | 公平投票可能产生不义结果，正确结果也可能来自排除程序 |
| 理想理论 / 非理想理论 | 设计正义制度与在现实压迫中决定行动需要不同假设 |
| 公共 / 私人 | 家庭与市场里的依赖、暴力和无偿劳动同样是政治问题 |

## 三、权威从哪里来

同意理论把政治义务连接到实际或假设同意，却面对多数人从未自由选择国家的问题；公平互惠理论认为接受合作收益者不能搭便车，但必须说明收益是否可拒绝、制度是否公平；工具主义以权威能更好协调、保护权利或帮助人依正确理由行动来辩护；民主理论诉诸平等参与和公共理由。哲学无政府主义则怀疑任何国家拥有普遍而内容独立的服从权。

“没有国家会混乱”至多支持某种制度必要性，尚未证明特定国家、特定命令或无条件服从。

## 四、自由、正义与权力的竞争图景

### 自由

消极自由关心他人干涉的范围；积极自由关心主体是否能自我治理；共和自由把问题放在是否受制于他人的任意支配。一个仁慈主人不干涉奴隶，仍保留随时干涉的权力，这说明无干涉可能不足以构成自由。

### 分配正义

- 功利路线重视制度产生的总体福祉；
- 罗尔斯式公平正义以平等基本自由、公平机会和最不利者的处境约束不平等；
- 自由至上路线强调自我所有、取得与转让，反对持续以某种分配图案重整财产；
- 能力路径追问人实际上能够成为什么、做什么，而非只看资源或主观满足；
- 平等主义、优先主义与充足主义分别把差距、较差者和最低门槛放在中心。

### 结构性权力

权力不只以命令出现，也通过议程、制度位置、知识分类、劳动分工和内化规范塑造可选项。女性主义政治哲学对公共—私人划分的批评表明：若家庭中的照护、依赖和暴力被宣布为私人事务，形式平等会掩盖实质支配。

## 五、论证实验室：无知之幕能推出什么

设想选择社会基本原则的人不知道自己的阶级、性别、族群、能力、宗教与人生计划，却知道一般社会事实。论证可以写成：

1. 公正原则不应由参与者偶然拥有的优势操纵；
2. 无知之幕排除这些特殊信息，同时保留选择所需的一般知识；
3. 在公平选择条件中理性选择的原则具有正义根据；
4. 因而，应以无知之幕后会选择的原则评价基本制度。

任务是检验第 3 步：选择者为何厌恶风险？为何优先保障最不利者而非最大化平均收益？不知道自身善观念的人是否仍能排序基本善？再让自由至上主义、能力路径或照护伦理提出最强异议。

## 六、跨传统压力：德治、兼爱与制度

儒家政治思想强调德性、角色责任与民生，墨家把兼爱、尚贤和公共利益推向更无偏的尺度，法家材料则凸显制度、赏罚和对私人德性的怀疑。三者会迫使现代契约模型面对一个问题：政治秩序主要依靠正当程序、良好统治者，还是可在普通动机下运行的制度？

比较不得把“德治”写成不要规则，也不得把“法”直接等同现代法治。需分别说明统治者受何约束、人民如何表达拒绝、错误怎样纠正。

## 七、四周课程

| 周次 | 阅读锚点 | 学习动作 | 必须产出 |
|---|---|---|---|
| 1 | 霍布斯《利维坦》13—18 章；SEP “Political Authority” | 从自然状态论证到权威，标明每一步 | 问题档案；一张权威论证图 |
| 2 | 密尔《论自由》第一、四章；SEP “Positive and Negative Liberty” | 用家长主义、伤害与支配分析三个政策 | 两张阅读卡；自由概念矩阵 |
| 3 | 罗尔斯《正义论》选段；SEP “Distributive Justice”“Feminist Political Philosophy” | 比较分配原则，并把家庭或照护纳入基本结构 | 钢人化异议；一次对话记录 |
| 4 | 《论语》《墨子》或《韩非子》选段；一项现实政策 | 写制度备忘录、反方审阅并整篇重写 | 2500—3500 字论文及修订说明 |

## 八、现实检验：一项制度怎样分配负担

选择住房、教育、医疗、数据治理或气候政策中的一项具体制度。建立“受影响者—利益—权力—风险”表，至少包含：直接受益者、承担成本者、没有正式发言权者和未来受影响者。

分别回答：

- 制度的强制由什么正当化；
- 它扩大哪一种自由，又限制哪一种自由；
- 它按平等、优先、充足还是权利分配；
- 决策程序如何允许异议和纠错；
- 家庭、市场或专业知识中的隐形权力是否改变结论。

## 九、结课论文与过关标准

可选问题：国家何时拥有正当权威？无干涉为何可能仍不自由？不平等在何种条件下可接受？家庭应在多大程度上成为正义对象？

通过必须做到：

- 全文不混淆权力、权威、合法律与合正当；
- 同时评价程序、结果和权力位置；
- 用一个制度案例比较至少三种正义原则；
- 纳入被主流模型遗漏的一类行动者；
- 给出可执行的纠错机制，而不只描述理想终点。
