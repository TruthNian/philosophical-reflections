# 实在、因果与时间：世界以什么方式存在

日常语言把“存在”“原因”和“时间”说得太顺手，仿佛它们只是经验中现成可见的东西。这个模块要追问：事物的存在依赖什么，一件事使另一件事发生意味着什么，过去、现在与未来是否具有不同的实在性。

## 一、问题边界

形而上学不是脱离事实的任意想象。它考察任何具体研究已经预设、却未必由单次观察决定的结构：什么东西存在，个体怎样保持同一，属性和关系如何依附，可能性是什么，原因和规律怎样连接，时间中的变化如何可能。

本模块不要求一次建成宇宙总论，而要求学习者看见自己的最低本体论承诺。例如：“算法造成歧视”已经承诺某种因果关系；“我还是十年前的我”已经承诺跨时间同一；“本可以不同”已经承诺某种可能性。

## 二、关键区分

| 区分 | 检查问题 |
|---|---|
| 存在 / 可知 | 无人能发现的东西是否因此不存在？ |
| 同一 / 相似 | 两个完全相似者是否就是同一个？ |
| 构成 / 同一 | 雕像与构成它的铜是否同一对象？ |
| 原因 / 相关 / 证据 | 烟是火的结果、相关项，还是火的证据？ |
| 因果 / 解释 | 数学事实能够解释，却通常不被称作事件原因 |
| 决定论 / 宿命论 | 前者谈状态与规律，后者说行动无论如何都不改变结果 |
| 时间的经验 / 时间的结构 | “当下很长”不能直接证明现在具有特殊本体地位 |

## 三、三组核心争论

### 什么存在

关于普遍者，可以主张“红”这样的性质独立于个别红物存在，也可以说它只是个别事物之间的相似、名称或概念。关于对象持续，可以用实体承载变化，以时空部分构成对象，或用关系连续性解释。选择越节省实体，解释负担可能越重；承认越多实体，存在承诺也越昂贵。

“什么都只是物质”同样不是没有形而上学的立场。它必须说明物质、规律、数学对象、意识与社会制度分别以何种方式存在。

### 什么叫造成

- **规律性路线**把因果理解为事件类型之间稳定相随；
- **反事实路线**追问：若原因没有发生，结果是否仍会发生；
- **机制路线**寻找产生、传递或组织结果的过程；
- **干预路线**用适当改变一个变量是否改变另一个来刻画因果；
- **因果力路线**把产生结果的能力放入事物本身。

先发事件、反事实依赖与机制各能处理部分案例，也各遭遇过度决定、共同原因、遗漏变量和因果抢占等困难。现实研究往往需要多种证据共同约束，而不是挑一个词宣布完成。

### 时间怎样存在

麦克塔加特式区分把事件按过去—现在—未来排列称为 A 系列，按早于—晚于关系排列称为 B 系列。现在主义只承认现在存在；永恒主义把不同时刻都纳入实在；增长块理论承认过去和现在、否认尚未发生的未来。任何立场都要解释变化、时间流逝经验和现代物理带来的压力。

## 四、论证实验室：因果是否只是恒常联结

重构休谟式压力：

1. 感官呈现事件的相继、接近与重复；
2. 感官从未呈现一个可观察的“必然联系”；
3. 我们关于必然联系的观念来自重复后形成的心理预期；
4. 因而，仅凭经验不能发现独立于这种预期的因果必然性。

先判断第 2 步是否从“不可直接观察”不当地跳到“不存在”。再选一个机制解释者、反事实理论或因果力理论作最强回应。回应必须处理两个病例：气压计读数与暴风雨相关但不造成暴风雨；两名纵火者各自足以烧毁房屋。

## 五、跨传统压力：实体还是关系

龙树《中论》关于缘起与空的论证，质问事物是否拥有不依条件而成立的自性。它并不简单断言“一切不存在”，而是把依存关系推到本体论中心。将其与亚里士多德式实体—属性框架比较时，至少检查三点：

1. 双方否定的对象是否相同；
2. “依存”是因果、概念、部分—整体还是语言依存；
3. 否认自性是否仍允许日常层面的对象和因果。

比较的结果可以是不相容，也可以是它们处理不同层次；不能只因词语相似便宣布会通。

## 六、四周课程

| 周次 | 阅读锚点 | 学习动作 | 必须产出 |
|---|---|---|---|
| 1 | SEP “Metaphysics”；亚里士多德《形而上学》Γ 卷选段 | 列出十条自己的存在承诺，分析雕像与铜案例 | 问题档案；概念区分表 |
| 2 | 休谟《人类理解研究》第七节；SEP “The Metaphysics of Causation” | 重构必然联系论证；比较规律、反事实和机制 | 两张阅读卡；一张论证图 |
| 3 | SEP “Time”；龙树《中论》第一、二、二十四品 | 比较两种时间观；分析缘起对实体观的压力 | 钢人化异议；一次对话记录 |
| 4 | 回到一个现实因果争议 | 用三种因果模型分析同一案例，写作并重写 | 2000—3000 字论文及修订说明 |

## 七、现实检验：一句“X 导致 Y”

选择一条真实因果主张，如“短视频降低注意力”“贫困导致犯罪”或“某项政策提高就业”。画出时间顺序、共同原因、中介变量、反馈回路和可能的选择偏差。分别写出：

- 相关数据最多支持什么；
- 什么干预或自然实验能增加因果可信度；
- 机制证据是什么；
- 哪种反事实无法实际观察，只能通过模型逼近。

最后把原句改写成证据真正支持的强度。哲学工作在这里不是替代统计学，而是防止“导致”一词越过证据。

## 八、结课任务与过关标准

论文从以下冲突中选择一个：实体与关系、规律与因果力、现在主义与永恒主义，或科学解释中的因果实在论与反实在论。

通过必须做到：

- 明示自己承认哪些基本存在者；
- 在至少一个案例中分开相关、原因和解释；
- 重构一项反对自身立场的最强论证；
- 说明跨传统概念能否真正对接；
- 让结论的力度不超过论证与证据。
