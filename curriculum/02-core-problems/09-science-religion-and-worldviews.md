# 科学、宗教与世界图景：不同求真实践如何相遇

科学、宗教和哲学都可能提出关于世界与人之位置的主张，但它们的对象、方法、证据和生活功能并不总相同。这个模块拒绝两种捷径：用“各有各的真理”免除冲突，也用“科学对宗教”这个单一战争故事覆盖不同科学与不同宗教传统。

## 一、问题边界

科学哲学追问观察、实验、模型、解释、归纳、证伪、范式和客观性。宗教哲学考察神圣、终极实在、信仰、宗教经验、恶、隐藏与多元性。科学与宗教关系则必须落到具体主张：宇宙年龄的经验判断、神迹的证据标准、创造的形而上学解释、苦难的宗教意义，并非同一种争论。

“世界图景”是关于实在、知识、人、价值与终极关切之间关系的一组主张。它不是一个无法检验的私人气氛；内部一致性、经验后果、解释范围和生活实践都能对它构成压力。

## 二、关键区分

| 区分 | 检查问题 |
|---|---|
| 科学结果 / 科学方法 / 科学主义 | 一项研究结论、形成结论的规范、把科学视为唯一知识分别需要论证 |
| 观察 / 数据 / 证据 | 仪器输出成为证据，需要校准、模型与背景假设 |
| 演绎 / 归纳 / 溯因 | 必然推出、概率推广与最佳解释具有不同强度 |
| 可证伪 / 已证伪 | 原则上面临风险，不等于一次异常就应抛弃理论 |
| 理论欠决定 / 任何理论都行 | 证据可能不唯一决定理论，不代表没有更好选择 |
| 方法论自然主义 / 形而上学自然主义 | 研究暂不诉诸超自然原因，不自动证明只有自然存在 |
| 宗教信念 / 信任 / 实践 / 身份 | 宗教不只是对若干命题打勾，但实践也包含可批评的主张 |
| 逻辑恶问题 / 证据恶问题 | “不可能并存”与“大量苦难使其不大可能”为不同论证 |
| 当前未解释 / 原则上不可解释 | 知识空缺不能自动支持神，也不能自动支持未来科学必能解释 |

## 三、科学方法不是一条固定算法

实验科学、历史科学、观察科学和模型密集型科学使用不同证据组合。假说演绎、统计推断、机制证据、稳健性分析和溯因各有位置。所谓“科学方法”更适合被理解为一组公开、可批评、可复查并受领域约束的实践规范，而不是从问题到真理的单一路径。

波普尔以可证伪性反对只会收集证实的理论；库恩说明正常科学、范式和革命怎样塑造问题与标准。前者不能被简化成“被反例击中即刻抛弃”，后者也不等于范式之间无法理性比较。研究史描述科学实际怎样变化，与规定好科学应怎样判断，必须同时存在又不能混同。

## 四、科学实在论与客观性

科学实在论通常认为成熟成功理论至少近似真实，且其不可观察实体并非只是假想工具；反实在论可以把理论理解为经验上充分的模型，而不承诺所有实体真实存在。“无奇迹论证”用科学成功支持实在论，悲观归纳则以过去成功理论后来被放弃施压。

客观性不是研究者没有价值或背景，而是主张能经受不同主体、方法和数据的系统批评。价值会进入研究问题、风险阈值和政策传递；关键是哪些价值影响不可避免，哪些影响扭曲证据，以及如何公开和制衡。

## 五、宗教主张的论证空间

宇宙论论证从偶然性、因果或充分理由走向必要根据；设计论证从秩序或精细调节走向智能解释；宗教经验论证把经验作为信念根据。反方会质问总体为何需要原因、解释是否停止得武断、概率如何设定、经验是否被传统塑造。

恶的问题则问全能、全知、全善的神与苦难能否或是否很可能并存。自由意志辩护、灵魂塑造和认知局限是不同回应。它们必须面对自然灾害、动物痛苦、规模和分布，而不能只解释人类恶行。

非有神论宗教传统会改变问题结构：终极问题也可能是苦与解脱、实在层次、修行转化，而不是造物主存在。因此，“宗教是否与科学冲突”必须先指明哪一传统、哪项主张、哪类证据。

## 六、论证实验室：归纳为什么可靠

休谟式论证可以重构为：

1. 从已观察到未观察的推断，预设自然在相关方面保持一致；
2. 这一一致性不能由演绎证明，因为否定它并不矛盾；
3. 若用过去的规律性归纳证明未来也规律，就循环使用了归纳；
4. 因而，归纳不能获得非循环的演绎或经验辩护。

分别测试四种回应：把归纳视为实践上不可避免；以可靠性而非主体辩护说明；用概率与先验更新重构；否认需要外部证明并转向具体方法的局部可靠性。每种回应要明说它是解决、消解还是接受问题。

再选一项宗教经验推断，与科学溯因比较：二者各有哪些独立证据、竞争解释、预测风险和纠错共同体？比较标准应一致，但不预设所有对象必须使用同一种仪器证据。

## 七、跨传统压力：先改变“宗教”的模型

选择一种有神论传统和一种非有神论或非造物论传统，分别列出它们的终极实在主张、核心实践、转化目标、证据观和内部异议。可以比较基督教创造与佛教缘起，也可以比较伊斯兰哲学的创造论与中国思想中的天、道或理。

比较不得把“佛教是科学”“儒家不是宗教”当作无需论证的结论。分类本身就是问题：它由哪些特征决定，又遗漏了什么？只有落到具体文本与实践，跨传统比较才不是文化标签。

## 八、四周课程

| 周次 | 阅读锚点 | 学习动作 | 必须产出 |
|---|---|---|---|
| 1 | 休谟《人类理解研究》第四、五节；SEP “Scientific Method” | 重构归纳问题，分析一项真实研究的证据链 | 问题档案；方法—证据矩阵 |
| 2 | 波普尔或库恩选段；SEP “Scientific Realism” | 用科学史案例区分描述、规范、证伪和理论转换 | 两张阅读卡；一张论证图 |
| 3 | SEP “Philosophy of Religion”“Religion and Science” | 重构一个有神论论证和一个恶的问题论证 | 钢人化异议；一次对话记录 |
| 4 | 一种非有神论传统原典；一个现实争议 | 建立世界图景比较表，写作、审阅并整篇重写 | 2500—3500 字论文及修订说明 |

## 九、现实检验：把一项争议拆成可判断的层次

选择疫苗、气候模型、意识研究、进化、祈祷疗效或生命起源中的一项争议。建立五层表：可观察数据、测量与模型、经验结论、形而上学解释、价值与行动决定。

标明争论实际发生在哪层，哪项证据能跨层支持，哪一步只是补充前提。若涉及高风险决定，还要写出错误成本、证据阈值和什么新信息会改变行动。不得以“科学已经证明”隐藏推论，也不得以“科学有局限”替代具体反证。

## 十、结课论文与过关标准

可选问题：归纳需要怎样的辩护？科学成功是否支持理论近似真实？价值能否被完全排除在科学之外？恶是否构成反对全能全善神的决定性理由？科学与宗教是否存在统一关系模型？

通过必须做到：

- 指明具体科学实践和具体宗教主张，不抽象交战；
- 区分经验结果、方法规范和形而上学外推；
- 对归纳、科学实在论或恶的问题作逐前提分析；
- 用同一套公开标准比较竞争解释；
- 明说自己的世界图景在哪些条件下会被修订。
