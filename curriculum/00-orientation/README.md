# 阶段 0：确定自己为什么学习哲学

定向阶段用五周建立思想基线。它不要求预先掌握任何哲学史，而是要求把已经支配生活的判断写出来。

## 完成目标

结束时应当拥有：

- 一份回答十二个根本问题的[世界观基线](../templates/worldview-baseline.md)；
- 一个愿意连续追问至少三个月的核心问题；
- 四张中文原典学习卡；
- 两张编号论证图；
- 一篇经过一次完整重写的 1000—2000 字短文。

## 五周安排

### 第一周：把隐蔽前提写出来

完成世界观基线。每道题都写：当前结论、两个理由、信心值、可能改变判断的条件，以及这一判断怎样影响生活。

不要查资料后再答。第一版的用途正是保留未经课程影响的自己。

### 第二周：建立问题地图

学习[《哲学从哪里开始：九个不能被常识迅速结束的问题》](../../learning/00-foundations/nine-philosophical-problems.md)。外文底本已由编写端核验，不是本周任务。

每个问题先写自己的答案，再读中文正文并修订。完成后选出三个标准：

1. 这个问题会真实改变我的生活或世界理解；
2. 至少存在两种各有理由的答案；
3. 我愿意承受答案可能推翻原有信念。

据此选定一个主问题。

### 第三周：看苏格拉底怎样追问

学习[《苏格拉底的申辩》中文学习页](../../reading-guides/ancient-greek/plato-apology.md)和[《游叙弗伦》中文学习页](../../reading-guides/ancient-greek/plato-euthyphro.md)。分别完成学习卡，并重构：

- 苏格拉底为何认为自己并未真正失败；
- “虔敬之所以虔敬，是因神喜爱，还是神因其虔敬而喜爱”怎样动摇权威式道德根据。

### 第四周：让另一种问题结构进入

从[《论语》中文学习页](../../reading-guides/chinese-east-asian/analects.md)或[《庄子·内篇》中文学习页](../../reading-guides/chinese-east-asian/zhuangzi-inner-chapters.md)中选一组学习。不要急着把它翻译成西方哲学术语；先问文本把修养、关系、语言或自由怎样组织成问题。原文章节号用于回源定位，不要求另找古籍或外文材料。

写一页比较：两种文本何处回答同一问题，何处根本没有在问同一件事。

### 第五周：写第一篇哲学短文

从以下题目选一项：

- 未经省察的生活是否不值得过？
- 善能否只由权威命令决定？
- 修养与规则何者更根本？
- 自由首先是摆脱外物，还是改变自己与外物的关系？

按[短论文模板](../templates/paper-workshop.md)完成初稿，隔一天后从头重写。只修改措辞不算重写；至少要改变一个前提、一个概念边界或对异议的回应。

## 过关标准

- 十二问没有空项；
- 核心问题可以用一个问句表达，而不是“人生哲学”之类宽泛主题；
- 能区分作者的主张和自己的判断；
- 短文有明确结论、编号论证、最强异议和回应；
- 能说出五周中哪一项判断发生了变化，以及为什么。

通过以后进入[哲学方法](../01-methods/README.md)。如果仍不知道自己为何而学，先重复第一、二周，不要用增加书目掩盖方向缺失。
