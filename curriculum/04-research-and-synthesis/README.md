# 专题研究与个人哲学：从学习者到可修订的作者

前面的课程训练理解、比较和判断；这一阶段要求完成两种更难的综合：一项别人能够核查的专题研究，以及一份自己愿意用生活检验、也愿意公开修订的个人哲学。

两者不能颠倒。没有研究训练的个人哲学容易变成偏好宣言；从不进入个人判断的研究又会变成只替文献排队。先用十六周完成一篇长论文，再用四周写个人哲学纲要。

## 二十周路线

| 周次 | 阶段 | 核心成果 |
|---:|---|---|
| 1—2 | [研究问题与提案](01-research-question-and-proposal.md) | 可争论问题、范围边界、可行性审计、研究提案 |
| 3—5 | [检索、文献矩阵与来源管理](02-literature-search-and-source-management.md) | 检索日志、文献矩阵、版本与引文库 |
| 6—8 | [贡献与论证设计](03-contribution-and-argument-design.md) | 争论地图、贡献测试、长文论证图 |
| 9—13 | [长论文起草与实质重写](04-long-paper-drafting-and-revision.md) | 完整初稿、结构稿、异议稿与证据稿 |
| 14—16 | [批评工坊与口头答辩](05-critique-workshop-and-oral-defense.md) | 批评档案、第二次重写、答辩和定稿 |
| 17—19 | [个人哲学纲要](06-personal-philosophy-constitution.md) | 八章暂行生活宪章、冲突图、实践承诺 |

## 专题研究必须形成什么

最终长文建议 5000—10000 字，必须同时具备：

- 一句可被否定、范围清楚的主要论题；
- 一项明确贡献：概念区分、论证、反例、文本解释、综合或应用；
- 8—12 项真正承担论证工作的核心来源；
- 对最强竞争立场的忠实重构；
- 至少一个能迫使论题收窄或改变的异议；
- 两轮改变结构或前提的完整重写；
- 引文、转述、版本、页码和事实逐项核验；
- 一次不依稿件复述的口头答辩。

文献数量不是成果。三十条引用也可以没有研究问题；八项材料若彼此形成真实压力，足以支撑一项小而清楚的推进。

## 个人哲学必须形成什么

个人哲学不是宇宙大全，也不是喜爱名句的拼贴。它是一份暂行宪章，说明：

1. 自己凭什么相信以及怎样分配信任；
2. 把人、自我、自由和责任理解成什么；
3. 什么构成善的生活，哪些价值不可交换；
4. 对亲近者、陌生人、制度、非人生命和未来者负什么责任；
5. 工作、爱、创造、政治参与、休息和独处如何排序；
6. 面对痛苦、失败、死亡和意义崩塌时依据什么行动；
7. 当价值真正冲突时采用什么优先和补救规则；
8. 什么证据、论证或生活失败会迫使这些条款修改。

每条主张都附理由、最强异议、实践含义和修订触发条件。声称珍视而长期不在时间、金钱、注意和关系中付出代价的价值，应被标为“愿望”，不能伪装成现行原则。

## 完成门槛

研究部分按[课程评估标准](../assessment.md)通过后，再检查四项：问题可行、贡献真实、来源可追、两次实质重写。个人哲学则必须经过冲突测试、现实记录和另一人的批评。

二十周结束时，提交一份总说明：研究怎样改变了个人哲学，个人利害又在哪些地方可能扭曲研究判断。能看见这种双向影响，比假装研究者没有立场更可靠。
