# 检索、文献矩阵与来源管理：建立争论，不是堆积书目

检索的目标不是“找到所有写过这个主题的人”，而是确认问题怎样被提出、主要立场如何论证、哪些材料被反复引用、真正开放的缺口在哪里。可靠研究必须让别人能够复现检索路径，也能追到每一项引文的版本和位置。

## 一、先写检索语言

为研究问题建立关键词矩阵：

| 类型 | 要写什么 |
|---|---|
| 核心概念 | 中文常用词、英文术语、必要时的原文词 |
| 同义与近义 | 不同学派或时期使用的替代表达 |
| 竞争立场 | 支持、反对、批评、回应所用术语 |
| 作者与作品 | 全名、异体拼写、作品简称、标准编号 |
| 方法词 | interpretation、objection、genealogy、experiment 等 |
| 排除词 | 容易把结果带向无关领域的高频词 |

不要过早固定一个译词。若“自由”在目标文献中可能对应 liberty、freedom、autonomy 或 agency，检索阶段先保留分支，解释阶段再区分。

## 二、四轮检索

### 第一轮：地图

用 SEP、IEP、专业手册或大学课程确认标准问题、主要立场和核心书目。导论负责给入口，不作为所有争议的最终证据。

### 第二轮：核心数据库

在 [PhilPapers](https://philpapers.org/) 以精确短语、作者、主题分类和年份组合检索。若研究跨学科，再进入相应专业数据库。记录完整查询式、日期、筛选条件和结果数量。

### 第三轮：引文链

从两到三篇核心材料同时向后看参考文献、向前看引用它们的研究。再追踪关键批评者的回应。只顺着一位作者的引文链会复制其阵营偏见。

### 第四轮：反向挑战

故意搜索“反驳主要论题”的词，加入另一传统、相邻概念和近五年材料。目标是寻找会推翻研究设计的文献，不是确认自己已经正确。

## 三、纳入、排除与停止规则

在阅读前写标准：

- 纳入何种语言、年份、体裁和问题相关度；
- 何种材料只作历史背景，何种材料能承担论证；
- 会议摘要、未审稿预印本、书评和博士论文分别怎样使用；
- 无法获得全文或无法核验版本时怎样标记。

停止检索不以“我看累了”为准。完成三次不同查询和两条独立引文链后，若新材料只增加例证、不再增加新立场、新论证或关键证据，可以暂时进入写作。出现新分歧时重新打开检索。

## 四、文献矩阵怎样写

每项材料只记录与研究问题有关的内容：

| 字段 | 作用 |
|---|---|
| 问题 | 作者实际回答什么，不按标题猜 |
| 主要结论 | 一句话，可被否定 |
| 编号论证 | 前提、推理和隐藏假设 |
| 方法与证据 | 文本、概念、案例、经验数据或历史档案 |
| 解释范围 | 结论覆盖什么、不覆盖什么 |
| 最强之处 | 它解释了竞争者难解释的什么 |
| 薄弱点 | 不是“我不同意”，而是具体负担 |
| 与其他材料关系 | 支持、修正、反驳、继承或互不相干 |
| 可用位置 | 长文哪一节为何需要它 |

完成矩阵后按争论关系重排，文学综述才会从“甲说、乙说、丙说”变成“争论在什么前提上分岔”。

## 五、版本、引文与文件

使用 Zotero 等引文管理工具保存完整元数据、DOI、稳定链接、访问日期与附件；标签只表示研究功能，如“核心论证”“反方”“历史背景”，不复制数据库主题词。

每项原典记录主版本、译者、出版年和标准编号。网络论文区分作者稿、预印本、接受稿和正式版本；引用时以实际阅读版本为准，并检查内容是否变化。用 [Crossref](https://search.crossref.org/) 核对 DOI，用 [Unpaywall](https://unpaywall.org/) 或机构仓储寻找合法开放版本，不上传无权传播的 PDF。

建议目录：

```text
research-topic/
  00-proposal/
  01-bibliography/
  02-reading-notes/
  03-argument-maps/
  04-drafts/
  05-feedback/
  06-final/
```

文件名使用“作者-年份-短标题”，笔记与 PDF 分开。来源存在不等于有权公开；仓库只保存自己的笔记、合法链接和合理短引文。

## 六、来源与事实审计

定稿前使用[来源审计表](../templates/source-audit.md)逐项检查：

- 引文是否与原文一致，删节是否改变语义；
- 转述是否真的由所引页支持；
- 作者原话、研究者解释和自己的推断是否分开；
- 版本、页码、章节、 DOI 和链接是否可追；
- 历史日期、人物关系和“首次提出”等事实是否有来源；
- 一项来源是否被用来支持超出其方法范围的结论；
- 反方是否只引用其最弱或过时版本。

若研究引入访谈、调查或个人敏感资料，先确认是否需要机构伦理审查、知情同意和数据保护。课程模板不能代替这些程序。

## 七、三周任务与过关标准

| 周次 | 动作 | 成果 |
|---|---|---|
| 3 | 建关键词矩阵，完成地图与数据库检索 | 检索日志；30 项候选书目 |
| 4 | 做双向引文链与反向挑战，筛核心材料 | 8—12 项核心书目；排除理由 |
| 5 | 精读并完成矩阵，整理版本与引文库 | [文献矩阵](../templates/literature-matrix.md)；来源审计初稿 |

通过必须做到：检索可复现，核心材料能覆盖主要冲突，至少三分之一材料对初始立场构成压力，每项引文可定位，文献矩阵按论证关系而非作者顺序组织。
