# 年度修订与生活检验：让哲学承担被现实改写的风险

一套只在纸上保持一致的哲学尚未经过生活。年度修订不是把宪章写得更漂亮，而是比较主张、选择、后果和新理由，找出哪些原则能够行动，哪些成为自我辩护，哪些在真实冲突中失效。

## 一、四类修订证据

- **事实压力：**关于世界、他人或自身能力的新证据；
- **论证压力：**无法回应的反例、矛盾或更好解释；
- **后果压力：**按原则行动反复产生其本想避免的伤害；
- **他者压力：**受影响者指出自己看不见的成本、权力或误述。

情绪变化本身不自动推翻原则，但可能提示被忽略的需要；行动失败也不自动证明原则错误，可能是能力、环境或执行问题。年度审计的任务正是区分这些原因。

## 二、建立双重账本

每月只记录三到五项重要决定：

| 决定 | 当时引用的条款 | 实际动机与约束 | 谁承担代价 | 结果 | 是否触发重审 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

另开[信念修订账本](../templates/belief-revision-ledger.md)，记录主张、信心、支持与反对证据、改变日期。不要为日常琐事制造全量监控；账本只保留能检验宪章的高信息事件。

## 三、区分四种不一致

1. **软弱：**仍接受原则，却在可控情形没有按它行动；
2. **冲突：**两个都接受的原则在具体情形不能同时满足；
3. **无能或受制：**资源、健康、强制或信息使行动不可行；
4. **原则错误：**即使执行良好，也产生无法辩护的结果。

把所有差距都叫虚伪会遮蔽制度约束，把所有差距都归因环境又会逃避责任。判断后分别采用训练、优先规则、改变条件或修订原则。

## 四、价值冲突时的六步程序

1. 列出受影响者和不可逆后果；
2. 分开事实不确定与价值冲突；
3. 找出不可越过的限制与可权衡利益；
4. 检查自己是否为自身关系或利益设置未公开例外；
5. 选择决定并说明未实现价值；
6. 安排补救、复查日期和会改变决定的新信息。

悲剧冲突可能没有不带损失的答案。承认道德余留并进行补救，比把最终选择宣布成全然正确更诚实。

## 五、一次年度审计

使用[年度复盘](../templates/annual-review.md)并增加以下比较：

- 去年与今年宪章逐条差异；
- 声称优先的价值与时间、金钱、注意分配是否相称；
- 最常使用的自我例外；
- 三项得到支持、三项受损、三项仍不可判定的条款；
- 哪位作者、哪项异议、哪个人或哪次失败造成了真实变化；
- 下一年唯一主问题及一项可以观察的生活实验。

旧版本永久保留。版本说明使用“新增、删除、收窄、增强、暂缓”五类，不用“思想更成熟”这种无法核查的总结。

## 六、第二十周与此后每年

第 20 周先完成第一次短周期审计：比较 v0.1、v1.0 及三周压力测试，建立 v1.1 和下一次年度日期。此后每年用一到两周进行审计，平时只维护双重账本。

每三年做一次盲重写：不看旧宪章，先独立回答八章问题，再比较旧版。这样能发现自己只是沿用熟悉措辞，还是判断真正保持。

## 七、过关标准

- 每项条款变化都能指出事实、论证、后果或他者压力；
- 行动差距被区分为软弱、冲突、受制或原则错误；
- 至少一项声称珍视但长期无成本的价值被降为向往或删除；
- 至少一项失败没有被合理化，而转化为明确修订；
- 旧版本、差异和仍未解决的问题完整保存；
- 下一年计划围绕一个主问题，不以无边界书单逃避生活检验。

个人哲学的可靠性不来自永不改变，而来自变化有理由、承诺有代价、错误能被看见。
