# 比较哲学：让另一种传统改变问题本身

比较哲学不是收集“东西方都说过”的相似名句，也不是把传统塑造成两个性格相反的文明。它在各自文本和历史中重构问题，再判断双方能否比较、在哪一层比较，以及比较如何暴露原有前提。

## 一、三种比较

### 同题异答

双方明确处理相近问题，却给出不同主张。例如人格连续性可以比较洛克的记忆理论与佛教无我论，但必须先说明二者各自的论敌与实践目标。

### 异题互照

双方并未回答同一问题，却能显示另一方的问题设定遗漏了什么。例如把伦理只理解为行为规则时，儒家修养论会迫使人重新考虑行动者如何形成。

### 概念迁移

一个传统的概念被用于重构另一语境中的问题。迁移必须说明原概念发生了什么变化，不能假定无损翻译。

## 二、六项对称原则

1. 双方都尽量使用原典和专业研究；
2. 双方都在内部语境中得到最强重构；
3. 不用一方的专业理论对比另一方的通俗格言；
4. 相似与差异都需要文本证据；
5. 不把文明、民族或语言当成单一思想主体；
6. 对自己熟悉的传统保持同等批判强度。

## 三、比较矩阵

| 维度 | 传统 A | 传统 B |
|---|---|---|
| 原始问题 |  |  |
| 论敌与语境 |  |  |
| 关键概念 |  |  |
| 核心论证 |  |  |
| 实践目标 |  |  |
| 最强异议 |  |  |
| 理论代价 |  |  |
| 比较后被改写的问题 |  |  |

最后一行最重要。若比较只得到“二者有相同点也有不同点”，它没有产生哲学成果。

## 四、翻译纪律

- 不因两个词都译成“道德”“心”“理性”便假定概念相同；
- 首次出现时说明工作译法和不被译出的含义；
- 比较概念在论证中的功能，而不只比较字面；
- 允许结论是“目前不可直接通约”；
- 不把不可通约理解为无法交流，而是需要建立更细的中介问题。

## 五、示例：自我与无我

洛克关心人格同一怎样跨时间延续，并把记忆或意识连续与责任联系起来。早期佛教的无我分析则在解脱实践中考察把五蕴执取为“我”所造成的痛苦。若直接问“双方是否相信灵魂”，会抹去各自问题。

有效比较应当进一步追问：责任是否需要一个持续实体？连续过程能否承担归责？把某种经验认作“我”在实践上做了什么？这样，另一传统不只提供答案，也改变了问题。

## 六、练习

从以下选一个：

- 亚里士多德的德性与《论语》的修身；
- 爱比克泰德的控制区分与《庄子》的逍遥；
- 洛克的人格同一与佛教无我；
- 康德的义务与墨家的兼爱、利害论证。

完成比较矩阵，再写 2000 字文章。文章前半必须分别完成内部重构，后半才允许比较。
