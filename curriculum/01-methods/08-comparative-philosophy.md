# 比较哲学：让另一种传统改变问题本身

> **状态：可直接学习。** 建议用时：四次各 3 小时，另加一次 100 分钟闭卷迁移。本文直接提供方法边界、操作协议、完整示范、练习、逐题参考答案和来源审计；完成本课不要求另读外部材料。

## 一、学完以后能够做什么

完成本课，你应当能够：

1. 把“东方重整体、西方重个人”一类文明性格句改写成有明确文本、时期和问题的比较；
2. 区分同题异答、异题互照和概念迁移三种比较任务；
3. 为双方分别重构问题、论敌、概念、论证、体裁、实践目标和历史边界；
4. 建立来源对称表，避免用一方原典和专业研究对比另一方名言或通俗概述；
5. 为不可直译的概念建立译词台账，说明工作译法、剩余意义和误导风险；
6. 区分语义、方法和评价三个层次的可通约与不可通约；
7. 设计一个“桥接问题”，让双方能在不被压成同一概念的前提下互相施压；
8. 同时证明相似和差异，写明比较在哪一层成立、在哪一层停止；
9. 把比较推进到建设性成果：修订问题、原则、案例或实践，而不只得到异同清单；
10. 用解释学与谱系检查翻译、选材、权力位置和自身偏好。

比较哲学的成果不在“古人早就说过”，也不在为某一文明争夺优越。它要使原本被当成普遍的问题显出地方前提，使陌生概念获得论证位置，并让双方都可能在比较中被修订。

## 二、比较哲学的三种任务

### 1. 同题异答

双方明确处理足够相近的问题，可以比较其答案。例如洛克与早期佛教都能进入人格连续和责任问题，但必须分别说明：洛克为何需要人格同一标准，佛教无我为何服务于解除执取。共同问题是研究结果，不是开头假定。

### 2. 异题互照

双方没有回答同一个原始问题，却能暴露对方遗漏。例如现代伦理若只问“该遵守哪条规则”，《论语》的修养与礼会迫使它增加“行动者如何形成”的问题。这里不是争夺同一道题的冠军，而是改变题目结构。

### 3. 概念迁移

把一个传统的概念带入另一语境，用来重构新问题。例如用佛教“执取”分析数字身份，或用亚里士多德“实践智慧”审查算法治理。迁移必然改变概念；合格做法要记录保留了什么、删去了什么、增加了什么，不能把新用途冒充原典原义。

三类任务可以连续发生：先在异题互照中发现遗漏，再建立桥接问题，最后形成经过标记的概念迁移。

## 三、适用与不适用场景

### 适合优先使用

| 场景 | 比较的价值 |
|---|---|
| 一个问题被单一传统的术语垄断 | 发现被排除的提问方式和证据 |
| 两套理论看似冲突却目标不同 | 区分真正分歧与错位争论 |
| 一个概念被译成相同中文 | 检查它们在论证和实践中的功能是否相同 |
| 现代理论在某类经验上反复失败 | 借另一传统提出桥接概念或新案例 |
| 课程想检验“哲学”的隐含定义 | 比较论证、格言、修行、对话和注疏等体裁 |
| 面对现实跨文化制度 | 防止把本地规范假装成无地域的中性标准 |

### 不宜单独承担

- 只需要解释一段文本时，先做解释学；
- 双方文本和版本身份都不清楚时，先做底本研究；
- 需要确定某项政策效果时，比较哲学不能替代经验评估；
- 只是寻找吸引人的相似名句时，尚未形成哲学问题；
- 比较单位是“亚洲人”“西方精神”等巨大主体时，应先缩小范围；
- 研究者无法取得任一方可靠译本或专业研究时，应把结论标为探索性，而不是强行对称；
- 现实争议涉及活着的社群时，纯文本比较不能替代其成员的发言、历史与权力关系。

不可比较也是一种可能结论，但必须说明阻碍发生在词义、问题、证据标准还是评价尺度，不能把“深奥”当作不可通约的证据。

## 四、核心概念与边界

### 1. 比较项

比较项是实际被比较的单位。它应当是“《尼各马可伦理学》第二、六卷对品格与实践智慧的关系”和“《论语》若干章对学、礼、仁与君子的关系”，而不是“希腊思想”和“中国思想”。单位越大，内部差异越容易被抹掉。

### 2. 内部重构与外部分析

内部重构先说明一项主张在其文本、体裁、论敌和实践中为何有意义；外部分析再用共享问题评价它。内部重构不等于无批判接受，外部评价也不拥有免检的中立语言。

### 3. 来源对称

对称不是两边机械使用相同页数，而是证据质量相当：原典对原典、专业研究对专业研究、最强版本对最强版本。若一方只留下残篇或可靠译本较少，应公开不对称并降低结论强度。

### 4. 翻译作为假说

把 *eudaimonia* 译成“幸福”或“兴盛”，把“仁”译成 *benevolence* 或 *humaneness*，每种选择都突出一部分、遮蔽一部分。工作译法是待检验的桥，不是概念已经同一的证明。

### 5. 桥接概念与桥接问题

桥接概念是一簇足够共享、又允许内部差异的问题资源，例如“行动者如何被训练成能在具体情境中作可靠判断”。它不声称 *phronēsis*、仁、礼完全相同，而是为它们建立可互相施压的工作台。

### 6. 三种可通约性

- **语义可通约：**能否足够准确地互译或指向同类对象；
- **方法可通约：**双方承认哪些理由、证据和反例；
- **评价可通约：**即使彼此理解，是否有共同标准裁定优劣。

词不可直译不等于完全不能理解；能互译也不保证有共同评价标准。结论应分别写三层。

### 7. 体裁与实践目标

系统论著、对话、格言、注疏、经、诗和修行手册以不同方式组织理由。《论语》的片段和人物判断不能被强迫伪装成亚里士多德式连续论证；反过来，也不能因其不按现代论文写作就免除一致性和证据检查。

### 8. 建设性参与

比较的高级成果是让双方资源参与一个仍然开放的问题：一方可能补足另一方，也可能揭示不可兼容前提，或共同生成第三种方案。建设性成果必须能追溯到双方内部重构，不能只借异国词汇装饰自己的理论。

### 9. 位置与权力

谁决定哪些传统算哲学、哪些译词成为标准、哪些文本代表整个文明，本身具有历史。研究者应记录语言能力、版本依赖、学术位置和现实受影响者。位置说明不是取消论证，而是暴露证据盲点。

## 五、十步操作协议

### 第 1 步：说明为何要比较

写出一个若不比较就会遗漏的问题，而不是“二者都很有名”。例如：

> “规则和单次选择不足以解释可靠品格怎样形成；两套古代修养论是否提供不同机制？”

### 第 2 步：限定比较项

为双方写明作者或文本、章节、时期、体裁和选取理由。禁止用文明名代替文本。若使用后世解释，必须与原典层分栏。

### 第 3 步：建立来源对称表

| 项目 | 传统 A | 传统 B |
|---|---|---|
| 原典与版本 |  |  |
| 可靠译本 |  |  |
| 历史语境研究 |  |  |
| 主要解释争议 |  |  |
| 研究者能力与依赖 |  |  |

缺项不会自动终止比较，却决定哪些结论只能暂定。

### 第 4 步：分别完成内部重构

在还不互相提及时，为每方各写七栏：原始问题、关键概念、主要主张、理由或文本推进、论敌、实践目标、内部代价。任一方若只剩一句名言，比较尚未开始。

### 第 5 步：建立译词台账

每个关键概念至少记录：原词、工作译法、在论证中的功能、不可保留的意义、容易误认成的另一概念。全文保持一致；若改译，记录改译原因。

### 第 6 步：提出桥接问题

桥接问题不能预设结论。例如“谁更重视关系”已把答案写入问题；“一个好行动者的判断怎样由训练、情感、关系和反思形成”则允许双方展示结构。

### 第 7 步：填比较矩阵

| 维度 | 传统 A | 传统 B | 可比层级 |
|---|---|---|---|
| 原始问题 |  |  | 同题／异题 |
| 人的能力模型 |  |  |  |
| 训练机制 |  |  |  |
| 情感与欲望 |  |  |  |
| 关系与制度 |  |  |  |
| 判断标准 |  |  |  |
| 理想生活 |  |  |  |
| 排除与代价 |  |  |  |

矩阵不以填满为目标。空格可能表明该维度对一方并不重要。

### 第 8 步：双向测试相似与差异

每个相似点都找一个会破坏它的差异，每个差异都找一个内部反例。若说“双方都重习惯”，要检查习惯的目的、载体和判断结构；若说“一方个人、一方关系”，要检查双方内部是否都有反例。

### 第 9 步：进行不对称与位置审计

检查：是否一方被当理论、一方被当智慧；是否熟悉方拥有丰富内部差异，陌生方只剩统一标签；是否现代问题只要求另一方提供资源，却不允许它改变评价标准；是否殖民、传教、翻译和学科制度影响了材料可见性。

### 第 10 步：形成建设性结论并标明停止点

最终交付四项：

1. 比较使原问题怎样改变；
2. 哪一主张得到支持、修订或反驳；
3. 新方案需要哪些额外事实或价值前提；
4. 哪些差异目前不可裁定，以及什么资料会改变结论。

“二者各有优点”不是停止点，而是拒绝判断。真正的停止点要说明证据或共同标准缺在哪里。

## 六、完整示范：亚里士多德与《论语》怎样塑造好行动者

这不是“希腊个人主义对中国集体主义”的比较。比较项限定为《尼各马可伦理学》中品格德性、习惯与实践智慧的关系，以及《论语》中学、礼、仁、义与君子养成的关系。详细文本课程可分别回到[《尼各马可伦理学》](../../reading-guides/ancient-greek/aristotle-nicomachean-ethics.md)与[《论语》](../../reading-guides/chinese-east-asian/analects.md)。

### 1. 为什么比较

初始问题：“规则知道了，为什么人仍不能稳定地做得好？”

初始猜想：“两者都是德性伦理，都认为靠习惯成为好人。”

这个猜想过早把两个传统放进现代分类。协议要求先拆开。

### 2. 限定比较项与体裁

亚里士多德文本是连续论证性的讲义／论著，目标与城邦政治教育相连。《论语》由言谈、场景和人物判断编成，意义常通过前后章、用词和典范人格显出。前者容易被过度系统化，后者容易被摘成格言。

修订一：“两套完整德性理论”改为“两种关于品格养成的文本结构，其中系统化程度和表达体裁不同”。

### 3. 来源对称表

| 证据层 | 亚里士多德侧 | 《论语》侧 | 本示范的处理 |
|---|---|---|---|
| 原典锚点 | 《尼各马可伦理学》I.7、II.1—6、VI.5、VI.12—13、X.6—9；正式研究应注明 Bekker 编号 | 通行章分的《论语》1.1、2.3、3.3、4.15、6.30、12.1、15.18、15.24；所链接本地底本把其中部分章分别作 6.28、15.23，故应同时注明篇名与关键词 | 双方都给可回查的位置，并公开版本章分差异，不拿一方原典对另一方概论 |
| 文本形成问题 | 讲授材料、卷次结构与编纂问题；古代城邦制度是论证背景 | 多层言论与场景汇编；篇章形成、人物归属和注疏传统存在争议 | 不把任何一部书当作一人一次写成且内部无张力的专著 |
| 现代研究 | 需核验品格德性、实践智慧、政治教育和第十卷生活理想的专业解释 | 需核验仁、礼、义、学习、编纂层与关系伦理的专业解释 | 每一争议至少检索双方各一项同等级研究，再写比较结论 |
| 当前材料上限 | 本仓库阅读课可定位论证，却不能替代希腊文本校勘与全部研究史 | 本仓库阅读课可定位章句，却不能替代古汉语、注疏与出土文献研究 | 这里只示范方法；超出材料的历史断言一律降为待核验假说 |

修订二：初始猜想没有来源边界。加入对称表后，结论只能覆盖所列原典锚点及可核验的解释，不能代表整个“希腊传统”或“中国传统”。

### 4. 双方内部重构

#### 亚里士多德一侧

- 原始问题：人的最高善如何在完整生活中成为活动；
- 核心概念：*eudaimonia*、*aretē*、习惯、选择、中道、*phronēsis*；
- 主要推进：品格德性由反复行动形成，成熟行动须知道、为行动本身选择并出于稳定状态；
- 判断机制：中道相对于行动者和情境，由实践智慧落实，不是数值平均；
- 情感位置：教育要使人在适当对象上以适当方式快乐和痛苦；
- 社会条件：法律、家庭、共同体和朋友参与品格形成；
- 代价：理想行动者以古代有闲男性公民为中心，财富、身份和奴隶制度边界必须被审查。

#### 《论语》一侧

- 原始问题：人在关系与政治失序中怎样经学习和实践成为君子；
- 核心概念：学、习、礼、仁、义、恕、君子；
- 主要推进：学习不是信息积累，而要在反复实践、温故、观察典范和纠正中进入行为；
- 判断机制：礼提供可练习的关系形式，义要求在具体处境中判断合宜，仁统摄对人的关切但没有单一定义句穷尽；
- 情感位置：孝悌、敬、忠恕和对礼的内在承担使行为不只是外在服从；
- 社会条件：家庭角色、师友、礼制和政治典范共同塑造行动者；
- 代价：等级、父权和角色服从可能被自然化，必须区分关系责任与不可申诉的支配。

修订三：共同点不是抽象的“德性”，而是两者都拒绝把伦理能力缩成知道规则；它们对训练载体和理想关系的说明不同。

### 5. 译词台账

| 原词 | 工作译法 | 功能 | 不能直接等同 |
|---|---|---|---|
| *eudaimonia* | 兴盛／活得好 | 完整生活的最高评价 | 当下幸福感 |
| *aretē* | 德性／卓越 | 使能力活动得好的稳定品质 | 道德服从 |
| *phronēsis* | 实践智慧 | 对可变行动和整体善作具体判断 | 高效率技巧 |
| 仁 | 仁／成就人的关系性德行 | 组织对人、角色和自我修养的要求 | 单一情绪“仁慈” |
| 礼 | 礼／礼仪规范与实践形式 | 训练身体、情感、角色和公共秩序 | 只指礼貌或仪式表面 |
| 义 | 合宜／正当判断 | 决定何者在具体关系中应当做 | 固定规则清单 |

修订四：把仁直接译成 virtue、把礼直接译成 habit，会提前制造相似。比较应放在功能层，不靠词典同义。

### 6. 桥接问题

桥接问题改为：

> “一个行动者怎样通过反复实践、情感塑造、典范关系和具体判断，取得既稳定又能应对变化的伦理能力？”

这个问题允许两者回答共同结构，也允许某一维度在一方更突出。

### 7. 比较矩阵

| 维度 | 亚里士多德 | 《论语》 | 判断 |
|---|---|---|---|
| 训练 | 重复行动形成品格 | 学与习、礼的反复实践 | 功能相近，制度内容不同 |
| 情感 | 恰当喜恶是成熟德性部分 | 敬、孝、恕等须进入关系实践 | 都超出外在服从 |
| 具体判断 | 中道与实践智慧 | 义与因时合宜 | 可桥接，不是同一理论 |
| 典范 | 实践智慧者与好人 | 君子、古代典范、师友 | 都依榜样，权威结构不同 |
| 共同体 | 城邦法律、友谊、家庭 | 家庭角色、礼制、政治示范 | 都非孤立个人伦理 |
| 最高结构 | 兴盛及沉思与实践的张力 | 仁、道、君子养成，无单一最高善论证 | 不宜强行同题 |
| 历史排除 | 公民身份、性别、奴隶制背景 | 等级、性别、宗法角色 | 都需独立规范审查 |

### 8. 双向反例

“亚里士多德只重个人”被城邦、法律和友谊材料推翻。“《论语》只重服从群体”被义对处境的判断、君子不盲从和自我修养推翻。“双方都讲中道”也过强：《论语》有权衡与合宜，却没有亚里士多德第二卷同样的中道定义和德目结构。

修订五：差异应落在理论组织、关系模型和判断资源，不落在“个人／集体”文明标签。

### 9. 不对称审计

若用亚里士多德的系统术语当比较表的标准，《论语》会显得缺定义；若用《论语》的关系场景当标准，亚里士多德会被误写成抽象。矩阵因此同时保留“论证结构”和“场景实践”，并承认《论语》内部编纂与解释争议、亚里士多德文本的讲义和编纂层。

修订六：证据对称不要求体裁相同，而要求不给任何一方因体裁差异而自动加分或免检。

### 10. 建设性结论

比较产生四项成果：

1. 道德教育不能只有规则，还要设计反复实践、反馈、情感和榜样；
2. 亚里士多德的实践智慧防止礼的实践退化成机械合规；
3. 《论语》的关系与礼提醒德性论：判断能力的载体不仅是个人状态，也包括可共同练习的互动形式；
4. 两者都可能把既有精英和等级当优秀判断的来源，因此现代方案必须加入平等地位、申诉和对榜样的公开审查。

最终结论不是把两者合成一套古代智慧。现代制度设计还需要心理学证据、权利原则和受影响者参与。比较完成的是问题修订和机制资源，不是政策自动生成。

## 七、常见失败模式与纠偏

| 失败 | 症状 | 纠偏 |
|---|---|---|
| 名句配对 | 两句都含“道”“心”“德”就宣布相同 | 重构句子所在问题、推进和实践功能 |
| 文明人格化 | “中国认为”“西方追求” | 限定作者、文本、时期、社群和争论 |
| 来源不对称 | 一方原典，另一方网文概述 | 建来源表，降低缺资料一方的结论强度 |
| 翻译坍缩 | 同一译词被当概念同一 | 建译词台账并记录剩余意义 |
| 体裁偏见 | 无形式论证就被判非哲学 | 检查对话、格言、实践和叙事如何给理由 |
| 只找相似 | 结果是“古人早已发现” | 每个相似点强制寻找破坏性差异 |
| 只找差异 | 结果是异国不可理解 | 为每个差异寻找内部反例和桥接层 |
| 假对称 | 机械要求双方回答同一栏 | 允许空格，说明原问题为何不同 |
| 选择性代表 | 用一个作者代表数千年传统 | 写明代表性限制并加入内部竞争者 |
| 借用不标记 | 现代方案披上传统词汇 | 记录概念迁移中的删改与新增 |
| 过早裁判 | 未内部重构就排优劣 | 先分别钢人化，再说明共同标准 |
| 温和相对主义 | 以“各有特色”逃避冲突 | 写明可裁定层、不可裁定层和所缺证据 |

## 八、强反对意见与方法局限

### 1. 桥接问题本身就是研究者发明的

这项异议正确。比较没有从无立场处开始。回应不是宣称桥完全中立，而是说明它怎样由双方问题约束、在哪些地方失真，并允许桥在比较中被改造。一个从未被任何一方修订的桥，通常只服务研究者原有理论。

### 2. 根本不可通约使比较失去意义

完全不可理解时确实无法比较，但实际情况常是局部可译、方法标准不同或评价尺度冲突。三层可通约分析能把“不能比较”拆成具体障碍。能够知道自己尚未理解，也已经比把差异压平更接近有效交流。

### 3. 比较必然挪用弱势传统

抽走概念、删去历史主体，再让强势学科取得解释权，确实会构成认识不正义。最低要求包括来源与译者可见、活传统参与、概念迁移留痕、现实利益和风险说明。即使满足这些条件，比较也可能需要停止，而不是默认所有资源都可取用。

### 4. 对称标准不可能完全实现

语言能力、材料保存和学科资源天然不平衡。方法要求的不是伪装绝对对称，而是公开不对称、补足弱项、邀请专业复核，并使结论强度与材料相称。

### 5. 内部重构可能冻结传统

传统内部本来就有跨文化接触、争议、改革和混合。所谓“内部”只是一个分析阶段，不是纯粹封闭本质。研究应记录文本的传播、译介和后世重构。

### 6. 比较不能自动产生规范优越性

相互启发不证明新方案正确。建设性结论仍须接受逻辑、经验、权利和后果检验。传统年代、文化代表性或双方都接受，都不是充分理由。

## 九、与解释学交叉校验

比较哲学最危险的环节是把解释假设当作比较事实。使用[解释学](06-hermeneutics.md)逐方校验：

1. 在整体—部分循环中检查关键词，不能靠单章确定全书；
2. 标明体裁、受众、论敌、编纂和译本差异；
3. 区分作者／文本可支持的意思、后世传统发展和课程迁移；
4. 用反例段落检验自己偏爱的读法；
5. 先让每方达到“其内部支持者能认出”的强度，再进入比较。

比较完成后再反向校验解释：另一传统可能揭示原解释漏掉的前提，但不能因此把外来问题冒充作者原问题。若比较需要改译关键概念，应回到原段落重新跑一轮解释学，而不是只修改矩阵。

谱系可作为第二层审计：为什么这两部文本被选为文明代表，译名与哲学正典如何形成，谁因比较获益或被消音。这些历史问题不替代文本判断，却决定结论的代表性。

## 十、练习：先独立完成

每题 10 分，总分 100 分。第 4、6、8、10 题任一低于 5 分，应重做协议相应步骤。

1. 区分同题异答、异题互照和概念迁移，并为每类各写一个新例子。
2. 把“东方哲学重和谐，西方哲学重自由”改写成两个可研究的限定比较。
3. 为比较斯多葛派与《庄子》建立来源对称表，列出五项必须核验的信息。
4. 分别为“康德义务”和“墨家兼爱／利害论证”写内部重构；本题禁止出现比较词。
5. 为“心、mind、xin”建立译词台账，说明为何同译成“心”仍不够。
6. 把“人怎样面对不可控制之事”改造成桥接问题，并列出四个不预设答案的维度。
7. 纠正推理：“亚里士多德讲德性，《论语》也讲德，所以二者拥有同一种德性伦理。”
8. 钢人化不可通约异议，分别判断语义、方法和评价层面可能卡在哪里。
9. 检查本课完整示范中的权力不对称：列出三项材料或研究位置风险，并提出修订。
10. 比较“佛教无我”与洛克人格同一，写 800—1000 字短文：双方内部重构、译词台账、桥接问题、一个真相似、一个真差异、建设性结论与停止点缺一不可。

## 十一、逐题参考答案与评分

### 第 1 题

同题异答比较相近问题的不同答案，如孟子与荀子怎样解释道德能力形成；异题互照让一方改变另一方问题，如现象学身体经验改写抽象心身问题；概念迁移把“礼”带入线上会议设计并明确改造。评分：三类定义各 2 分，三个有效新例各 1 分，说明三类可连续发生 1 分。

### 第 2 题

可改为：“《论语》中特定礼、和与义的段落，和密尔《论自由》中个人自由与社会干预的论证，怎样处理冲突与公共秩序？”另一项可比较“《庄子·齐物论》对固定是非的审查”与“柏林消极／积极自由区分”怎样设定强制问题。评分：每项明确文本 2 分、明确问题 2 分，共 8 分；删除文明人格化 1 分；标明两项并非代表全部传统 1 分。

### 第 3 题

表中至少应有：爱比克泰德或塞涅卡的具体文本与版本；《庄子》的篇章及内外杂篇层；双方可靠译本；各自历史语境与主要解释争议；研究者语言能力和二手依赖。评分：五项各 1.5 分，共 7.5 分；说明原典对原典、研究对研究 1.5 分；写出一项无法补齐时的降级策略 1 分。

### 第 4 题

康德侧应写普遍法则、自律、出于义务的动机和人格作为目的，并说明其反对以倾向或结果作为唯一根据。墨家侧应写兼相爱、交相利与对差等之爱的批评，并以上古圣王范例、天下利害与天志等不同层次的理由推进；这些理由分布于不同篇章，不能压成一次论证。评分：双方各含问题、概念、主张、理由四项，各 4 分；两方都没有偷用对方术语 2 分。

### 第 5 题

台账应区分英文 *mind* 在不同理论中可指认知主体或心理能力；古汉语“心”常同时涉及思虑、情感、欲求和道德判断；现代中文“心”还有器官和情感义。必须记录具体文本功能，不能建立跨传统固定词典。评分：三个语境各 2 分，两个误译风险各 1 分，提出按段落功能改译 2 分。

### 第 6 题

桥接问题可写：“行动者怎样区分可改变与不可改变的条件，并在不确定中调整判断、欲望和行动？”维度可包括控制对象、判断训练、情感变化、社会关系、行动目标中的任四项。评分：问题不预设一方正确 4 分，四维各 1 分，说明桥会被双方修订 2 分。

### 第 7 题

相同中文词不能证明概念同一。须比较 *aretē* 与“德”在最高善、能力、礼、政治角色和具体判断中的功能；亚里士多德有中道与实践智慧的系统论证，《论语》以学、礼、仁、义和君子场景推进。稳健结论只说二者都研究品格养成，具体理论结构不同。评分：指出词面谬误 3 分，双方内部功能各 2 分，限定相似 2 分，保留体裁差异 1 分。

### 第 8 题

最强异议是：概念嵌在整套生活与理由标准中，抽离后对象已改变。语义层可能无一词对译；方法层可能一方重演绎、一方重典范修习；评价层可能彼此理解却没有共同优先价值。回应应采用局部桥接并允许不可裁定。评分：异议 3 分，三层各 1.5 分，共 4.5 分，局部回应 1.5 分，明确停止条件 1 分。

### 第 9 题

风险包括：希腊原典与《论语》译注掌握不对称；“德性伦理”是现代分类，容易让亚里士多德成为默认标准；可见正典排除女性、劳动者和非精英实践。修订可加入双方专业复核、以多个桥接维度而非单一德性框架、明确历史排除并加入相关材料。评分：三项风险各 2 分，相应修订各 1 分，共 9 分；说明位置公开不等于论证无效 1 分。

### 第 10 题

合格答案应分别说明洛克为何以意识连续处理人格、归责和法庭性概念，早期佛教为何以五蕴非我解除执取；台账区分 person、self、attā、人格与自我；桥接问题可问责任需要哪种连续；真相似是都拒绝用身体实体单独解决；真差异是洛克寻找人格同一条件，SN 22.59 主要解除把五蕴认作我；建设性结论可发展无实体但有记忆、意向和因果连续的责任模型；停止点是单篇经文与洛克文本都不足以决定现代法律全部标准。评分：题目所列七项各 1 分，来源边界 1 分，双向反例 1 分，新方案所需额外前提 1 分。

**总分核对：10 × 10 = 100。**

## 十二、闭卷迁移任务

完成正文至少 24 小时后，关闭本页，限时 100 分钟比较以下两个压缩材料包：

- **材料 A：**爱比克泰德式训练把判断、欲求和冲动列为在我们范围内，把身体、声誉、职位和外部结果列为不能完全支配；自由来自训练同意与欲望，而非控制世界。
- **材料 B：**《庄子》的多则故事通过技艺、视角转换和对固定成见的松动，展示行动者怎样顺应事物纹理；它没有给出一张与斯多葛派相同的控制二分表。

交付一张两页比较报告：

1. 说明比较目的；
2. 限定文本与材料不足；
3. 分别内部重构，不得先贴“顺其自然”标签；
4. 建立五词译词台账；
5. 写一个桥接问题和六维矩阵；
6. 给出两个相似及各自的破坏性差异；
7. 给出两个差异及各自的内部反例；
8. 做来源、体裁和研究者位置审计；
9. 提出一个可用于现代焦虑管理的迁移方案；
10. 写明该方案不能由两份材料直接证明什么。

十项中至少八项合格，且第 3、4、6、10 项必须合格。若结论只是“二者都主张接受不能改变之事”，视为未通过。
