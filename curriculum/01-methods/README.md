# 阶段 1：哲学方法

哲学没有一种能够解决全部问题的万能方法。逻辑与论证是公共底座；苏格拉底式反诘、概念分析、思想实验、现象学、解释学、谱系和比较哲学分别揭示不同类型的盲点。

已经带着具体问题进入时，可用[跨层学习导航](../cross-index.md)选择第一种方法，再用另一种方法检查其遗漏。

## 方法选择

| 面对的困难 | 优先方法 |
|---|---|
| 一组信念互相冲突 | 苏格拉底式反诘 |
| 同一个词在争论中不断变义 | 概念分析 |
| 原则在极端案例中产生反直觉结果 | 思想实验与反思平衡 |
| 理论忽略经验在第一人称中的结构 | 现象学 |
| 文本意义受语言、体裁和时代影响 | 解释学 |
| 一种观念把历史产物伪装成自然事实 | 谱系 |
| 一个传统的问题设定被误当成普遍前提 | 比较哲学 |
| 任何理由是否真的支持结论 | 论证与逻辑 |

## 方法完成标准

学习者面对一个新问题，应当能够：

1. 先重构论证，而不是立即选择立场；
2. 说明自己为何选择某种方法；
3. 说出该方法能揭示什么、不能单独证明什么；
4. 用另一种方法检查第一种方法遗漏的内容；
5. 把方法结果写成可接受异议的短论文。

方法只是调查手段。把自己变成“分析哲学的人”“现象学的人”或“谱系批判的人”，会使方法从工具变成新的盲点。
