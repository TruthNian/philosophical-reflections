# 苏格拉底式反诘：让一组信念接受彼此检验

苏格拉底式反诘不是连续说“为什么”，更不是用问题迫使别人接受预设答案。它把一个自信断言与说话者同样愿意接受的其他信念放在一起，检查它们能否共存。

## 一、基本结构

1. 对方提出主张 P；
2. 共同澄清 P 中的关键词；
3. 引出对方同样接受的命题 Q、R；
4. 发现 P 与 Q、R 不能同时成立；
5. 判断应放弃、缩小还是重写哪一个命题；
6. 新定义再次接受反例。

目标不是把对方逼到无话可说，而是发现原先看不见的矛盾。

## 二、示例：“自由就是想做什么就做什么”

初始主张：自由就是能够满足自己的欲望。

连续检验：

- 成瘾者强烈想摄入某种物质并成功做到，他因此更自由吗？
- 一个欲望由操纵、恐惧或长期驯化产生，满足它仍然算自由吗？
- 若两个同时存在的欲望冲突，哪一个代表“自己”？
- 能够拒绝最强欲望，是否反而更接近自由？

原定义因此必须区分：行动不受外部阻碍、欲望的来源、反思后认同的欲望，以及控制行动的能力。反诘没有直接给出自由的最终定义，却证明了原定义过窄。

## 三、一份可执行的反诘记录

| 步骤 | 记录内容 |
|---|---|
| 主张 | 用一句可真可假的话表达 |
| 定义 | 关键词当前指什么 |
| 承诺 | 主张者同时接受哪些相关判断 |
| 压力案例 | 哪个真实或假想案例造成冲突 |
| 冲突 | 哪些命题不能同时为真 |
| 修订 | 删除、缩小或重新定义什么 |
| 余留问题 | 新版本在哪些案例上仍不稳定 |

## 四、反诘的纪律

- 一次只追一项主张；
- 先确认复述得到对方认可；
- 问题必须允许真实回答，不能把结论藏进问句；
- 对自己喜欢的立场采用同样强度；
- 发现矛盾后停下来修订，不把尴尬当作胜利；
- 区分“对方答不出来”与“命题已经被反驳”。

反诘尤其适合处理道德自信、政治口号和未经界定的生活原则；它不适合单独确认历史事实或经验因果，后者需要证据调查。

## 五、练习

从以下主张选一个：

- 只要不伤害别人，人就可以做任何事；
- 真正的爱不应当附带条件；
- 努力就应当得到回报；
- 每个人都有自己的真理；
- 服从法律就是正义。

完成至少十轮追问，最后写出：原主张、造成压力的承诺、修订版本、仍未解决之处。再让另一人对你的修订版本做同样反诘。
