# 七条思想史主干：看见问题怎样迁移、断裂与重生

核心问题课程把不同传统放在同一争论平面；思想史课程反过来恢复距离。一个概念在什么制度、语言和实践中出现，经过谁的编纂、翻译与评论，又为何在后世被改造成今天熟悉的样子，都是理解的一部分。

这一阶段用三十五周建立七条主干，每条五周、约四十小时。目标不是记住一条从古至今的胜利路线，而是获得足以纠正时代错置、经典神话和单一文明叙事的历史判断力。

每条主干的锚点现已直接连接到对应原典导读；从具体问题进入时，先用[跨层学习导航](../cross-index.md)确认历史比较与问题比较没有被混成同一种关系。

## 思想史不是哲学家的接力赛

课程拒绝四种常见写法：

- **目的论：**把过去写成通向今天正确观念的准备阶段；
- **孤立论：**把传统当成边界不变、彼此无交流的文明容器；
- **伟人论：**只列名家，不研究学校、寺院、宫廷、大学、殖民制度和出版网络；
- **标签论：**用“理性主义”“儒家”“西方”“东方”等后设分类代替文本内部差异。

历史语境可以解释一个论证为何出现，却不能单凭起源判定它真假；当代标准可以批评过去，却不能替代先弄清作者究竟在回答什么。

## 每条主干使用三副镜头

| 镜头 | 核心问题 | 典型证据 |
|---|---|---|
| 问题与论证 | 当时争论什么，概念和推理怎样变化？ | 原典、论证重构、同时代批评 |
| 实践与制度 | 谁能学习、写作和保存文本，思想用于何种生活？ | 学校、寺院、宫廷、大学、社团、出版史 |
| 传承与重构 | 文本怎样被编纂、翻译、注释、遗忘和重新发现？ | 手稿、译本、评注、课程与正典史 |

三者不能互相取代。只讲制度会把哲学化约成利益，只讲论证会把无历史的现代问题投射给古人，只讲影响则会把相似误写成因果传承。

“锚点”负责让学习者进入一部作品的结构，不代表它能代表整个传统。其余文本用短篇或稳定章节形成争论，不能让锚点变成文明代言人。

## 每条主干的五周循环

| 周次 | 工作 | 成果 |
|---|---|---|
| 1 | 建立年代、地理、语言、制度和来源地图 | 一张带不确定性标记的历史图 |
| 2 | 精读锚点 A，恢复它的同时代问题 | 阅读卡与论证图 |
| 3 | 精读锚点 B，以内部异议打破单一传统 | 阅读卡与论证图 |
| 4 | 追踪一次翻译、评注、制度传播或后世重构 | 一份传承档案与对话记录 |
| 5 | 写史学判断，接受反例并重写 | 3000—4000 字历史论证论文 |

历史图上的日期分为“文献确定”“学界通说”“存在重大争议”三类。不得用一个精确年份掩盖实际不确定性。

## 统一成果

每条主干必须留下：

1. 一条至少十二节点的时间线，其中至少三个节点是翻译、制度或文本传承事件；
2. 两份[阅读卡](../templates/reading-card.md)与两张[论证图](../templates/argument-map.md)；
3. 一份“概念迁移档案”，比较一个词在两个时期或语言中的功能；
4. 一张内部争论图，至少包含三个不能被同一标签抹平的立场；
5. 一篇具有明确史学论题、原典证据和竞争解释的论文。

完成七条后，制作一张不以欧洲为中心轴的同步时间图：在同一横向年代上放置各区域事件，并画出实际可证的翻译或交流路径。没有证据的相似只标为比较，不画成影响关系。

## 过关标准

除[课程通用评估](../assessment.md)外，思想史论文还必须满足：

- 不用后世标签直接替代作者自用概念；
- 至少呈现一次传统内部的真实冲突；
- 把文本留存、翻译或制度条件纳入解释；
- 区分历史因果、概念相似与后世挪用；
- 对一个常见历史叙事提出证据充分的修订；
- 既不以语境为错误开脱，也不以今天的结论取消理解。

任何一条主干缺少原典论证和传承证据，即使时间线完整，也只能算文化常识，不能通过。
