# 仓库内中文学习契约

这套课程的读者端只有一个入口：本仓库。原典、外文版、论文和网页属于编写端的证据层，不是学习者必须另行完成的阅读任务。

## 一、完成标准

一项内容只有同时满足以下条件，才可以标记为“可直接学习”：

1. 中文正文独立说明问题从哪里产生，而不是只列书名、术语或阅读提示；
2. 关键概念有定义、边界、易混项和至少一个具体例子；
3. 主要立场被重构为前提—结论结构，隐含前提得到标示；
4. 至少提出一个会真正改变结论的强异议，并说明可能的修订方向；
5. 区分作者的明确主张、学界解释、编者重构和进一步判断；
6. 有练习、作答要求和自查标准，读者能够检验自己是否真的理解；
7. 有来源审计，编者能够返回原典核对版本、章节、页码或稳定编号；
8. 学习任务不以“再去读某本外文书”作为缺失正文的替代品。

课程表、书单和导读提纲本身都不算教材。只有交付了上述正文和检验环节，才算完成一个学习单元。

## 二、学习者与编写者的分工

| 角色 | 必须做 | 不必做 |
|---|---|---|
| 学习者 | 阅读仓库中文正文；独立作答；画论证图；根据异议修订判断 | 阅读外文原版；自行寻找版本；在多个网站之间拼接材料 |
| 编写者 | 阅读并核验原典；处理版本和译词；重构论证；补足语境、异议、练习和答案标准 | 把书单转交给学习者后宣布课程已经完成 |
| 原典书库 | 为编写、复核和日后修订提供稳定底本 | 充当公开下载区或读者的必修书架 |

原文仍然重要，但重要性体现在证据可追溯，而不是把语言困难原样转嫁给读者。学习者只有在主动研究某个译词、解释争议或文本细节时，才进入可选的“原文核验”路径。

## 三、两种文本处理方式

### 公版或开放许可作品

在确认原文与所用译本均可合法再发布后，可以制作完整中文翻译。完整译文必须说明：

- 原作与底本身份；
- 译者、版本和许可或公版依据；
- 标准章节号或原页码；
- 关键译词与存在实质分歧的句子；
- 校对状态与尚未解决的问题。

完整翻译不是逐词搬运。忠实意味着保存命题关系、语气、概念复现和论证转折，也意味着不为了中文顺滑而悄悄替作者补论证。

### 仍受版权保护的现代作品

公开仓库不发布整书、整章、连续长段或足以替代原书的逐章翻译。处理方式是：

- 以问题为单位重写自足的中文教学正文；
- 用编者自己的结构重构概念和论证，而非沿原书逐段改写；
- 只引用证明解释所必需的最短片段；
- 给出版本、章节或节号，使每项归属能够回查；
- 明确哪些内容来自原书，哪些是比较、批评或课程扩展。

这不是降低准确性。准确性由版本核对、论证重构和来源审计保证；公开范围则由作品权利状态决定。

## 四、三层保存边界

| 层级 | 内容 | 边界 |
|---|---|---|
| 公开课程 | 原创中文教材、必要短引文、公版或开放许可译文 | 应尽可能详细、深入、易懂、全面、具体 |
| 私人补充 | 个人译词卡、连续段落核验、私人学习稿和个人作答 | 仅限获授权账户；私密性不等于自动取得翻译或复制许可 |
| 本地证据库 | 购买或提供的完整 PDF、EPUB、扫描本 | 不上传 GitHub，不通过课程重新分发 |

GitHub 的可见性作用于仓库整体，公开仓库中的普通文件不能单独设为私密。私人补充因此使用独立私密仓库。公开课程仍须独立交付主要问题、概念、论证、异议、案例和练习，不把私人链接当作缺失正文的替代品。

## 五、每个学习单元的固定结构

1. **问题与目标**：学完能够解释、区分和完成什么；
2. **中文教学正文**：不依赖外部材料的完整讲解；
3. **概念工具**：定义、反例、边界和常见混淆；
4. **论证地图**：编号论证、隐含前提、最弱环节；
5. **立场比较**：至少两个可成立而互相施压的答案；
6. **强异议与修订**：不使用假想稻草人；
7. **生活或制度案例**：检验理论在真实处境中的后果；
8. **练习与自查**：包含作答格式、评分点或参考分析；
9. **来源审计**：仅供编写与进阶核验，不构成学习前提。

### 深度递进

“易懂”不是删去困难，而是安排困难出现的次序。每个成熟单元应允许同一读者逐层进入：

1. **直观入口**：用真实案例让问题发生，不用轶事代替论证；
2. **精确骨架**：定义概念，写出前提、结论、反例和适用范围；
3. **理论分岔**：比较主要立场各自保存了什么、牺牲了什么；
4. **历史与文本深层**：说明问题为何在特定语境出现，以及解释争议怎样改变结论；
5. **现实检验**：进入生活、制度、科学或政治案例，处理尺度和副作用；
6. **独立研究接口**：留下版本、章节、争议文献和仍未解决的问题，供愿意继续深入者使用。

“全面”也不等于堆满人物和术语。一个单元至少应覆盖该问题不可绕过的主要答案、最强反例、重要历史来源、跨传统差异和现实后果；无法纳入的内容要明确写成边界，而不是静默遗漏。

## 六、状态标签

- **可直接学习**：满足全部八项完成标准；
- **正文已成，待补检验**：中文解释和论证已经存在，练习答案或来源审计尚不完整；
- **编写中**：已有可靠底本，尚未形成自足中文教材；
- **路线项**：只确定了课程位置，不能当作已交付内容；
- **待取得底本**：编写端缺少足以核对的可靠版本。

以后仓库中的“已完成”只表示第一种状态。课程结构搭好、文件已经下载或书目已经列出，都不再冒充内容完成。

## 七、质量复核

发布前必须通过两次检查：

1. **闭卷检查**：审校者不打开原书，只凭中文单元能否复现问题、论证、异议和适用边界；
2. **回源检查**：重新打开底本，逐项确认作者归属、章节定位、关键术语和版本差异。

闭卷检查保证仓库可以学习，回源检查保证它没有为了易懂而失真。两者缺一不可。
