# 学习模板

模板把“我大概懂了”变成可以检查的记录。复制文件后用日期和主题命名，例如：

```text
2026-08-24-free-will-question-dossier.md
2026-09-03-descartes-meditation-2-reading-card.md
```

## 模板目录

- [世界观基线](worldview-baseline.md)：课程开始和每年末使用；
- [问题档案](question-dossier.md)：每个四周模块的主文件；
- [阅读卡](reading-card.md)：每部原典或论文一张；
- [论证图](argument-map.md)：重构并检验一个核心论证；
- [短论文工作稿](paper-workshop.md)：保留初稿、批评和重写依据；
- [对话记录](dialogue-record.md)：记录真正分歧与改变条件；
- [周复盘](weekly-review.md)：维持节奏并发现理解缺口；
- [年度复盘](annual-review.md)：重做世界观、审查成果并设计下一年。

模板只保留能改变学习判断的字段。不要为了“笔记完整”重复抄写已经能够从书中找到的内容。
