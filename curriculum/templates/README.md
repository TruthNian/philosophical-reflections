# 学习模板

模板把“我大概懂了”变成可以检查的记录。复制文件后用日期和主题命名，例如：

```text
2026-08-24-free-will-question-dossier.md
2026-09-03-descartes-meditation-2-reading-card.md
```

## 课程学习模板

- [世界观基线](worldview-baseline.md)：课程开始和每年末使用；
- [问题档案](question-dossier.md)：每个四周模块的主文件；
- [阅读卡](reading-card.md)：每部原典或论文一张；
- [论证图](argument-map.md)：重构并检验一个核心论证；
- [短论文工作稿](paper-workshop.md)：保留初稿、批评和重写依据；
- [对话记录](dialogue-record.md)：记录真正分歧与改变条件；
- [周复盘](weekly-review.md)：维持节奏并发现理解缺口；
- [年度复盘](annual-review.md)：重做世界观、审查成果并设计下一年。
- [学习完成账本](completion-ledger.md)：用文件位置、评估、口试与随机复核证明各阶段完成。

## 专题研究模板

- [研究提案](research-proposal.md)：缩小问题、测试贡献和可行性；
- [检索日志与文献矩阵](literature-matrix.md)：复现检索并按论证关系组织研究；
- [来源审计表](source-audit.md)：逐项核验版本、引文、转述、事实与权利；
- [长论文论证图](long-paper-map.md)：连接论题阶梯、前提、证据和章节功能；
- [异议登记表](objection-register.md)：钢人化批评并记录采纳、收窄或拒绝；
- [研究完成记录](research-completion-record.md)：说明最终贡献、失败、边界与复现位置。

## 个人综合模板

- [个人哲学宪章](personal-philosophy-constitution.md)：写八章条款、现实成本和修订触发；
- [信念修订账本](belief-revision-ledger.md)：记录信心变化及其事实、论证、后果或他者压力。

模板只保留能改变学习判断的字段。不要为了“笔记完整”重复抄写已经能够从书中找到的内容。
